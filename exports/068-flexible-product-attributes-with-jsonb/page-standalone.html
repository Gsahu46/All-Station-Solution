The problem in real life

  1. 140 columns

    Phones need RAM and storage, shoes need size and colour, sarees need fabric. Each new category added columns that are empty for every other product.

  2. Everything in JSON

    The first fix put the whole product in one jsonb column. A seller typed "free" as the price, and every customer's price filter failed. Duplicate SKUs and unknown sellers got in too.

  3. The fix

    Columns for what every product has and the rules it needs; jsonb only for what differs per category, checked against that category's rules.

Flexible data still needs rules. Keep the rules close to the data.

What are we building?

POST /products adds a product with its category's attributes, checked; GET /products?attr.ram=8GB finds products by any mix of attributes, through an index.

An everyday analogy

A registration form: printed boxes everyone fills (name, price, seller), and a page of extra questions that depends on what you register: a phone asks for RAM, a shoe for size. The clerk checks the extra page against that type's list.

How it works in 4 steps

  1. Check the printed boxes: SKU, name, price range, seller.
  2. Load the category's rules and check the attributes: known names, allowed values, nothing required missing.
  3. Store the fixed fields in columns, the attributes as one jsonb object.
  4. Search with "the attributes contain these pairs", answered by the GIN index.
Check yourself: should "brand" be a column or an attribute?

If every product has a brand, people filter and sort by it, and brands are their own table you join to, it is a column with a foreign key. If only some categories have it and it is just shown, an attribute is fine. The test is the one in this station: does it need a constraint or a join?

What this station is not

  • No admin screen for rules. Rules are rows; Practice 1 reads them.
  • No numeric ranges on attributes. Values are text; "RAM at least 8GB" needs typed attributes.
  • No document database. That is station 070.

Business problem

Kartwala (a fictional marketplace) has a products table with 140 nullable columns, one set per category.

Acceptance criteria

Demo data: phones need ram and storage (colour optional); shoes need size and colour (material optional).

  1. Given a phone with ram, storage and colour, then 201 with the attributes stored.
  2. Given a shoe of size 13 with ram and no colour, then 422 naming each problem.
  3. Given an unknown category or seller, then 422; a duplicate SKU, 409.
  4. Given attr.ram=8GB&attr.storage=256GB, then only products with both.
  5. Given an attribute no category has (or not this category), then 400.
  6. Given any search, then the GIN index is used.

Requirements

  • Price, seller, category and SKU are columns with constraints.
  • Attributes are a jsonb object, checked against the category's rules before saving.
  • A new category or attribute is a row in attribute_definitions, not a release.
  • Searches use containment, which the GIN index answers.

Learning objectives

  • Store and query jsonb from Java.
  • Index jsonb with GIN and know which operators use it.
  • Validate per-category attributes from data.
  • Decide what is a column and what is an attribute.

The trap

Plausible but wrong

Putting everything in jsonb, including fields that need constraints and joins.

The test builds the old table: one data column per product, price and seller inside. Then:

  • Anything gets in. A second PH-NOVA-8-128, a price of "free", seller 999, RAM "lots": all accepted. There is nothing to attach a constraint to.
  • One bad row breaks everyone. (data->>'price')::int < 200000 worked, until the "free" row: then it fails for every customer with "invalid input syntax for type integer: "free"".
  • The real table refuses the same rows: products_sku_unique, products_price_range, products_seller_fk.
  • The index only helps the right operator. attributes @> '{"ram": "12GB"}' uses the GIN index; attributes->>'ram' = '12GB' reads every row.

While building, each fix was undone once: without the allowed-values check, the required check, the search's name check, the GIN index, or the "must be an object" CHECK, 1 test turned red each.

        this.catalog = catalog;
    }

    @PostMapping("/products")
    ResponseEntity<ProductCatalog.Product> create(@Valid @RequestBody NewProduct body) {
        ProductCatalog.Product created = catalog.create(new ProductCatalog.NewProduct(body.sku().toUpperCase(Locale.ROOT), body.name().strip(),
                body.category(), body.sellerId(), body.pricePaise(), body.attributes()));
        return ResponseEntity.created(URI.create("/products/" + created.id())).body(created);
    }

    /** ?category=phones&attr.ram=8GB&attr.storage=128GB: every attr.* pair must match. */
    @GetMapping("/products")
    List<ProductCatalog.Product> search(@RequestParam Map<String, String> params) {
        Map<String, String> wanted = new TreeMap<>();
        params.forEach((key, value) -> {
            if (key.startsWith("attr.")) {
                wanted.put(key.substring(5), value);
            } else if (!key.equals("category")) {
                throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "Unknown parameter " + key);
            }
        });
        if (wanted.isEmpty() || wanted.size() > 10) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "Give 1 to 10 attr.<name>=<value> filters");
        }
        return catalog.search(params.get("category"), wanted);
    }

package com.kartwala.attributes;

import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.server.ResponseStatusException;
import tools.jackson.core.type.TypeReference;
import tools.jackson.databind.json.JsonMapper;

import java.util.List;
import java.util.Map;
import java.util.TreeMap;

@Service
class ProductCatalog {

    record NewProduct(String sku, String name, String category, long sellerId, int pricePaise, Map<String, String> attributes) {
    }

    record Product(long id, String sku, String name, String category, long sellerId, int pricePaise, Map<String, String> attributes) {
    }

    private static final TypeReference<TreeMap<String, String>> MAP = new TypeReference<>() {
    };
    private static final String COLUMNS = "id, sku, name, category_code, seller_id, price_paise, attributes::text AS attributes";

    private final JdbcClient jdbc;
    private final AttributeRules rules;
    private final JsonMapper json;

    ProductCatalog(JdbcClient jdbc, AttributeRules rules, JsonMapper json) {
        this.jdbc = jdbc;
        this.rules = rules;
        this.json = json;
    }

    Product create(NewProduct p) {
        Map<String, AttributeRules.Rule> categoryRules = rules.of(p.category());
        if (categoryRules.isEmpty()) {
            throw new ResponseStatusException(HttpStatus.UNPROCESSABLE_CONTENT, "No category " + p.category());
        }
        Map<String, String> problems = rules.problems(categoryRules, p.attributes());
        if (!problems.isEmpty()) {
            ProblemDetail detail = ProblemDetail.forStatusAndDetail(HttpStatus.UNPROCESSABLE_CONTENT, "These attributes do not fit a " + p.category() + " product");
            detail.setProperty("attributes", problems);
            throw new ErrorResponseException(HttpStatus.UNPROCESSABLE_CONTENT, detail, null);
        }
        try {
            long id = jdbc.sql("""
                            INSERT INTO products (sku, name, category_code, seller_id, price_paise, attributes)
                            VALUES (?, ?, ?, ?, ?, CAST(? AS jsonb)) RETURNING id""")
                    .params(p.sku(), p.name(), p.category(), p.sellerId(), p.pricePaise(), json.writeValueAsString(p.attributes()))
                    .query(Long.class).single();
            return byId(id);
        } catch (DuplicateKeyException e) {
            throw new ResponseStatusException(HttpStatus.CONFLICT, "SKU " + p.sku() + " already exists");
        } catch (DataIntegrityViolationException e) {
            throw new ResponseStatusException(HttpStatus.UNPROCESSABLE_CONTENT, "No seller " + p.sellerId());   // the only other foreign key left
        }
    }

    Product byId(long id) {
        return jdbc.sql("SELECT " + COLUMNS + " FROM products WHERE id = ?").param(id).query((rs, i) -> new Product(rs.getLong("id"),
                rs.getString("sku"), rs.getString("name"), rs.getString("category_code"), rs.getLong("seller_id"), rs.getInt("price_paise"),
                json.readValue(rs.getString("attributes"), MAP))).single();
    }

    /** Containment (@>): "the attributes include all of these pairs", which the GIN index answers. */
    List<Product> search(String category, Map<String, String> wanted) {
        if (category != null && rules.of(category).isEmpty()) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No category " + category);
        }
        List<String> known = (category == null ? jdbc.sql("SELECT DISTINCT name FROM attribute_definitions")
                : jdbc.sql("SELECT name FROM attribute_definitions WHERE category_code = ?").param(category)).query(String.class).list();
        wanted.keySet().stream().filter(name -> !known.contains(name)).findFirst().ifPresent(name -> {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No attribute " + name + (category == null ? "" : " for " + category));
        });
        JdbcClient.StatementSpec query = jdbc.sql("SELECT " + COLUMNS + " FROM products WHERE attributes @> CAST(:wanted AS jsonb)"
                + (category == null ? "" : " AND category_code = :category") + " ORDER BY id LIMIT 50").param("wanted", json.writeValueAsString(wanted));
        if (category != null) {
            query = query.param("category", category);
        }
        return query.query((rs, i) -> new Product(rs.getLong("id"), rs.getString("sku"), rs.getString("name"), rs.getString("category_code"),
                        rs.getLong("seller_id"), rs.getInt("price_paise"), json.readValue(rs.getString("attributes"), MAP))).list();
    }
}

package com.kartwala.attributes;

import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Component;

import java.sql.Array;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

/** The attribute rules of a category, read from attribute_definitions, and the check a new product must pass. */
@Component
class AttributeRules {

    record Rule(String name, boolean required, List<String> allowed) {
    }

    private final JdbcClient jdbc;

    AttributeRules(JdbcClient jdbc) {
        this.jdbc = jdbc;
    }

    /** Name to rule, for one category; empty if the category does not exist. */
    Map<String, Rule> of(String category) {
        Map<String, Rule> rules = new LinkedHashMap<>();
        jdbc.sql("SELECT name, required, allowed FROM attribute_definitions WHERE category_code = ? ORDER BY name").param(category)
                .query((rs, i) -> {
                    Array allowed = rs.getArray("allowed");
                    return new Rule(rs.getString("name"), rs.getBoolean("required"), allowed == null ? null : Arrays.asList((String[]) allowed.getArray()));
                }).list().forEach(r -> rules.put(r.name(), r));
        return rules;
    }

    /** Every problem with these attributes, by attribute name; empty means valid. */
    Map<String, String> problems(Map<String, Rule> rules, Map<String, String> attributes) {
        Map<String, String> problems = new TreeMap<>();
        attributes.forEach((name, value) -> {
            Rule rule = rules.get(name);
            if (rule == null) {
                problems.put(name, "not an attribute of this category; known: " + rules.keySet());
            } else if (rule.allowed() != null && !rule.allowed().contains(value)) {
                problems.put(name, "must be one of " + rule.allowed());
            }
        });
        List<String> missing = new ArrayList<>();
        rules.values().stream().filter(r -> r.required() && !attributes.containsKey(r.name())).forEach(r -> missing.add(r.name()));
        missing.forEach(name -> problems.put(name, "is required"));
        return problems;
    }
}

package com.kartwala.attributes;

import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.server.ResponseStatusException;
import tools.jackson.core.type.TypeReference;
import tools.jackson.databind.json.JsonMapper;

import java.util.List;
import java.util.Map;
import java.util.TreeMap;

@Service
class ProductCatalog {

    record NewProduct(String sku, String name, String category, long sellerId, int pricePaise, Map<String, String> attributes) {
    }

    record Product(long id, String sku, String name, String category, long sellerId, int pricePaise, Map<String, String> attributes) {
    }

    private static final TypeReference<TreeMap<String, String>> MAP = new TypeReference<>() {
    };
    private static final String COLUMNS = "id, sku, name, category_code, seller_id, price_paise, attributes::text AS attributes";

    private final JdbcClient jdbc;
    private final AttributeRules rules;
    private final JsonMapper json;

    ProductCatalog(JdbcClient jdbc, AttributeRules rules, JsonMapper json) {
        this.jdbc = jdbc;
        this.rules = rules;
        this.json = json;
    }

    Product create(NewProduct p) {
        Map<String, AttributeRules.Rule> categoryRules = rules.of(p.category());
        if (categoryRules.isEmpty()) {
            throw new ResponseStatusException(HttpStatus.UNPROCESSABLE_CONTENT, "No category " + p.category());
        }
        Map<String, String> problems = rules.problems(categoryRules, p.attributes());
        if (!problems.isEmpty()) {
            ProblemDetail detail = ProblemDetail.forStatusAndDetail(HttpStatus.UNPROCESSABLE_CONTENT, "These attributes do not fit a " + p.category() + " product");
            detail.setProperty("attributes", problems);
            throw new ErrorResponseException(HttpStatus.UNPROCESSABLE_CONTENT, detail, null);
        }
        try {
            long id = jdbc.sql("""
                            INSERT INTO products (sku, name, category_code, seller_id, price_paise, attributes)
                            VALUES (?, ?, ?, ?, ?, CAST(? AS jsonb)) RETURNING id""")
                    .params(p.sku(), p.name(), p.category(), p.sellerId(), p.pricePaise(), json.writeValueAsString(p.attributes()))
                    .query(Long.class).single();
            return byId(id);
        } catch (DuplicateKeyException e) {
            throw new ResponseStatusException(HttpStatus.CONFLICT, "SKU " + p.sku() + " already exists");
        } catch (DataIntegrityViolationException e) {
            throw new ResponseStatusException(HttpStatus.UNPROCESSABLE_CONTENT, "No seller " + p.sellerId());   // the only other foreign key left
        }
    }

    Product byId(long id) {
        return jdbc.sql("SELECT " + COLUMNS + " FROM products WHERE id = ?").param(id).query((rs, i) -> new Product(rs.getLong("id"),
                rs.getString("sku"), rs.getString("name"), rs.getString("category_code"), rs.getLong("seller_id"), rs.getInt("price_paise"),
                json.readValue(rs.getString("attributes"), MAP))).single();
    }

    /** Challenge 1: the rules, for a form. */
    List<AttributeRules.Rule> rulesOf(String category) {
        List<AttributeRules.Rule> list = List.copyOf(rules.of(category).values());
        if (list.isEmpty()) {
            throw new ResponseStatusException(HttpStatus.NOT_FOUND, "No category " + category);
        }
        return list;
    }

    /** Challenge 2: GROUP BY one attribute's value (->>), filtered with the same containment as the search. */
    Map<String, Long> facet(String category, String facet, Map<String, String> wanted) {
        if (!rules.of(category).containsKey(facet)) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No attribute " + facet + " for " + category);
        }
        Map<String, Long> counts = new TreeMap<>();
        jdbc.sql("""
                        SELECT attributes->>:facet AS value, count(*) AS n FROM products
                        WHERE category_code = :category AND attributes @> CAST(:wanted AS jsonb) AND attributes->>:facet IS NOT NULL   -- not "attributes ? :facet": JDBC reads that ? as a placeholder
                        GROUP BY 1""")
                .param("facet", facet).param("category", category).param("wanted", json.writeValueAsString(wanted))
                .query((rs, i) -> counts.put(rs.getString("value"), rs.getLong("n"))).list();
        return counts;
    }

    /** Containment (@>): "the attributes include all of these pairs", which the GIN index answers. */
    List<Product> search(String category, Map<String, String> wanted) {
        if (category != null && rules.of(category).isEmpty()) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No category " + category);
        }
        List<String> known = (category == null ? jdbc.sql("SELECT DISTINCT name FROM attribute_definitions")
                : jdbc.sql("SELECT name FROM attribute_definitions WHERE category_code = ?").param(category)).query(String.class).list();
        wanted.keySet().stream().filter(name -> !known.contains(name)).findFirst().ifPresent(name -> {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No attribute " + name + (category == null ? "" : " for " + category));
        });
        JdbcClient.StatementSpec query = jdbc.sql("SELECT " + COLUMNS + " FROM products WHERE attributes @> CAST(:wanted AS jsonb)"
                + (category == null ? "" : " AND category_code = :category") + " ORDER BY id LIMIT 50").param("wanted", json.writeValueAsString(wanted));
        if (category != null) {
            query = query.param("category", category);
        }
        return query.query((rs, i) -> new Product(rs.getLong("id"), rs.getString("sku"), rs.getString("name"), rs.getString("category_code"),
                        rs.getLong("seller_id"), rs.getInt("price_paise"), json.readValue(rs.getString("attributes"), MAP))).list();
    }
}

                            VALUES (?, ?, ?, ?, ?, CAST(? AS jsonb)) RETURNING id""")
                    .params(p.sku(), p.name(), p.category(), p.sellerId(), p.pricePaise(), json.writeValueAsString(p.attributes()))
                    .query(Long.class).single();
            return byId(id);
        } catch (DuplicateKeyException e) {
            throw new ResponseStatusException(HttpStatus.CONFLICT, "SKU " + p.sku() + " already exists");
        } catch (DataIntegrityViolationException e) {
            throw new ResponseStatusException(HttpStatus.UNPROCESSABLE_CONTENT, "No seller " + p.sellerId());   // the only other foreign key left
        }
    }

    Product byId(long id) {
        return jdbc.sql("SELECT " + COLUMNS + " FROM products WHERE id = ?").param(id).query((rs, i) -> new Product(rs.getLong("id"),
                rs.getString("sku"), rs.getString("name"), rs.getString("category_code"), rs.getLong("seller_id"), rs.getInt("price_paise"),
                json.readValue(rs.getString("attributes"), MAP))).single();
    }

    /** Challenge 1: the rules, for a form. */
    List<AttributeRules.Rule> rulesOf(String category) {
        List<AttributeRules.Rule> list = List.copyOf(rules.of(category).values());
        if (list.isEmpty()) {
            throw new ResponseStatusException(HttpStatus.NOT_FOUND, "No category " + category);
        }
        return list;
    }

    /** Challenge 2: GROUP BY one attribute's value (->>), filtered with the same containment as the search. */
    Map<String, Long> facet(String category, String facet, Map<String, String> wanted) {
        if (!rules.of(category).containsKey(facet)) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No attribute " + facet + " for " + category);
        }
        Map<String, Long> counts = new TreeMap<>();
        jdbc.sql("""
                        SELECT attributes->>:facet AS value, count(*) AS n FROM products
                        WHERE category_code = :category AND attributes @> CAST(:wanted AS jsonb) AND attributes->>:facet IS NOT NULL   -- not "attributes ? :facet": JDBC reads that ? as a placeholder
                        GROUP BY 1""")
                .param("facet", facet).param("category", category).param("wanted", json.writeValueAsString(wanted))
                .query((rs, i) -> counts.put(rs.getString("value"), rs.getLong("n"))).list();
        return counts;
    }

    /** Containment (@>): "the attributes include all of these pairs", which the GIN index answers. */
    List<Product> search(String category, Map<String, String> wanted) {
        if (category != null && rules.of(category).isEmpty()) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No category " + category);
        }
        List<String> known = (category == null ? jdbc.sql("SELECT DISTINCT name FROM attribute_definitions")
                : jdbc.sql("SELECT name FROM attribute_definitions WHERE category_code = ?").param(category)).query(String.class).list();
        wanted.keySet().stream().filter(name -> !known.contains(name)).findFirst().ifPresent(name -> {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "No attribute " + name + (category == null ? "" : " for " + category));
        });
        JdbcClient.StatementSpec query = jdbc.sql("SELECT " + COLUMNS + " FROM products WHERE attributes @> CAST(:wanted AS jsonb)"
                + (category == null ? "" : " AND category_code = :category") + " ORDER BY id LIMIT 50").param("wanted", json.writeValueAsString(wanted));
        if (category != null) {
            query = query.param("category", category);
        }
        return query.query((rs, i) -> new Product(rs.getLong("id"), rs.getString("sku"), rs.getString("name"), rs.getString("category_code"),
                        rs.getLong("seller_id"), rs.getInt("price_paise"), json.readValue(rs.getString("attributes"), MAP))).list();
    }
}

Interview takeaways

json or jsonb?

jsonb: stored parsed, so it can be indexed and queried efficiently; json keeps the exact text, including key order and duplicates.

Which jsonb queries can a GIN index answer?

With jsonb_ops: containment (@>), key existence (?, ?|, ?&) and jsonpath; with jsonb_path_ops: containment and jsonpath only, with a smaller index.

When should a field be a column instead of jsonb?

When every row has it, it needs a constraint, it is joined, or it is computed with; jsonb cannot carry those rules.

How do you validate jsonb?

In the app, against rules (here a table per category); in the database, at least its shape with CHECK constraints.

What is the risk of casting a jsonb value in a query?

One row with an unexpected value makes the cast fail and the whole query fail for every user.
