The problem in real life

  1. A PDF from two releases ago

    Dakroute's partners integrate from a PDF someone wrote by hand. It says weight_kg and origin; the API takes weightGrams and fromPincode.

  2. 200 tickets a month

    Every partner who copies the PDF's example gets 400, writes to support, and waits. Nobody updated the PDF when the API changed, because nothing made them.

  3. The fix

    The docs are generated from the code, with the errors and examples in it, and a test sends every example to the API and compares the answers. A change to the docs shows as a diff to review.

Docs that nothing checks will drift. Generate them from the code and test them against the API.

What are we building?

A rate-quote endpoint whose OpenAPI description is generated from the code, documents every error with an example, and is tested so that every example really works.

An everyday analogy

A recipe printed straight from the kitchen's own cards, and tasted: every recipe in the book is cooked once before the book is printed.

How it works in 4 steps

  1. Describe in code: field limits come from the validation annotations, descriptions and examples from annotations next to them.
  2. Generate: springdoc serves the description at /v3/api-docs.
  3. Test it: every example is sent; every documented answer is compared with the real one.
  4. Review it: the description is compared with an approved copy; a change shows as a diff in the pull request.
Check yourself: the docs are generated from the code. Can they still be wrong?

Yes. springdoc first said weightGrams was optional, because it only knows @NotNull, while the API refused a request without it. The test that removes each field found it: see Tests.

What this station is not

  • No docs website. The description is JSON; Swagger UI or Redoc can show it (one more dependency).
  • No real tariff. Zones and prices are demo rules.
  • No booking. A quote is a price.

Business problem

Dakroute (a fictional courier): partners integrate from a stale PDF and open 200 tickets a month.

Acceptance criteria

Demo tariff: same first three PIN digits LOCAL (₹40 per started 500 g), same first two REGIONAL (₹55), else NATIONAL (₹75); EXPRESS half as much again; chargeable weight is the larger of actual and volumetric (L×W×H cm / 5, in grams); GST 18%; at most 50 kg; PIN codes 744101 and 194101 not served.

  1. Given a valid parcel, then 200 with the zone, chargeable weight, price, GST and total in paise.
  2. Given invalid input, then 400; a parcel the network cannot carry, 422.
  3. Given /v3/api-docs, then an OpenAPI description with every field's limits, every error, and examples.
  4. Given any example in the docs, then sending it gets the documented status and answer.
  5. Given a change to the API, then the description differs from the approved copy until someone reviews and approves it.

Requirements

  • No hand-written docs that can disagree with the code.
  • Errors documented with examples, not only the happy path.
  • The docs' required fields are exactly the ones the API refuses without.

Learning objectives

  • Generate OpenAPI with springdoc and enrich it with annotations.
  • Document errors and examples that are true.
  • Test docs against the API instead of trusting them.
  • Review API changes as diffs of the description.

The trap

Plausible but wrong

Hand-written docs that drift from the real API.

  • The PDF. The test sends the PDF's own example to the API: 400. Nothing ever checked the PDF, so nothing noticed.
  • Generated docs. The description's request schema has exactly the fields the API takes, with the PIN code pattern and the size limits from the validation annotations.
  • Generated is not enough. The generated docs were wrong twice while building (see Tests). Only the tests that send the examples and compare the answers caught it.

While building, each part was undone once: an int field not marked required in the docs turned 2 tests red; a wrong total in a documented example 2; a field renamed 7; the weight limit changed 3; another volumetric divisor 1; GST cut instead of rounded 1; no LOCAL zone 1; no rounding up to a started slab 3.

class HandWrittenDocsTrapTest extends ApiTest {

    /** Page 4 of "Dakroute Rate API v2.pdf". */

            {"origin": "560001", "destination": "110001", "weight_kg": 1.2, "dimensions": "30x20x10", "type": "surface"}""";

package com.dakroute.rates;

import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.media.Content;
import io.swagger.v3.oas.annotations.media.ExampleObject;
import io.swagger.v3.oas.annotations.media.Schema;
import io.swagger.v3.oas.annotations.responses.ApiResponse;
import jakarta.validation.Valid;
import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Pattern;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

import java.util.concurrent.atomic.AtomicLong;

/**
 * The partner docs are generated from this code: the paths, the fields with their limits (from the validation
 * annotations), the errors and the examples. Every example here is sent to the API by a test, so it cannot drift.
 */
@RestController
class RateQuoteController {

    // int fields are marked required by hand: Jackson 3 refuses a missing int (400), but springdoc only knows @NotNull.
    @Schema(description = "A parcel to price.")
    record QuoteRequest(
            @Schema(description = "Pickup PIN code: six digits, not starting with 0.", example = "560001")
            @NotNull @Pattern(regexp = "[1-9][0-9]{5}") String fromPincode,
            @Schema(description = "Delivery PIN code.", example = "110001")
            @NotNull @Pattern(regexp = "[1-9][0-9]{5}") String toPincode,
            @Schema(description = "Actual weight in grams. Above 50,000 g the parcel service cannot carry it (422).", requiredMode = Schema.RequiredMode.REQUIRED, example = "1200")
            @Min(1) int weightGrams,
            @Schema(description = "Length in cm.", requiredMode = Schema.RequiredMode.REQUIRED, example = "30") @Min(1) @Max(150) int lengthCm,
            @Schema(description = "Width in cm.", requiredMode = Schema.RequiredMode.REQUIRED, example = "20") @Min(1) @Max(150) int widthCm,
            @Schema(description = "Height in cm.", requiredMode = Schema.RequiredMode.REQUIRED, example = "10") @Min(1) @Max(150) int heightCm,
            @Schema(description = "STANDARD or EXPRESS.", example = "STANDARD") @NotNull RateCard.Service service) {
    }

    @Schema(description = "A price for one parcel. Amounts are integer paise (₹1 = 100 paise).")
    record Quote(@Schema(example = "Q-1") String quoteId, RateCard.Zone zone,
                 @Schema(description = "The larger of actual and volumetric weight.") long chargeableWeightGrams,
                 long pricePaise, @Schema(description = "GST at 18%.") long gstPaise, long totalPaise,
                 @Schema(description = "Working days, a demo estimate.") int estimatedDays) {
    }

    static final String PARCEL = """
            {"fromPincode": "560001", "toPincode": "110001", "weightGrams": 1200, "lengthCm": 30, "widthCm": 20, "heightCm": 10, "service": "STANDARD"}""";
    static final String PARCEL_QUOTE = """
            {"quoteId": "Q-1", "zone": "NATIONAL", "chargeableWeightGrams": 1200, "pricePaise": 22500, "gstPaise": 4050, "totalPaise": 26550, "estimatedDays": 5}""";
    static final String LIGHT_BUT_BULKY = """
            {"fromPincode": "560001", "toPincode": "560034", "weightGrams": 800, "lengthCm": 60, "widthCm": 40, "heightCm": 40, "service": "EXPRESS"}""";
    static final String TOO_HEAVY = """
            {"fromPincode": "560001", "toPincode": "110001", "weightGrams": 62000, "lengthCm": 80, "widthCm": 60, "heightCm": 60, "service": "STANDARD"}""";
    static final String BAD_PINCODE = """
            {"fromPincode": "56001", "toPincode": "110001", "weightGrams": 1200, "lengthCm": 30, "widthCm": 20, "heightCm": 10, "service": "STANDARD"}""";

    private final AtomicLong quotes = new AtomicLong();

    @Operation(summary = "Quote a shipping rate", description = "Prices one parcel between two PIN codes. Nothing is booked: a quote is a price, not a shipment.")
    @io.swagger.v3.oas.annotations.parameters.RequestBody(content = @Content(mediaType = "application/json", examples = {
            @ExampleObject(name = "parcel", summary = "A 1.2 kg parcel, Bengaluru to Delhi (200)", value = PARCEL),
            @ExampleObject(name = "light-but-bulky", summary = "Volumetric weight counts (200)", value = LIGHT_BUT_BULKY),
            @ExampleObject(name = "too-heavy", summary = "62 kg (422)", value = TOO_HEAVY),
            @ExampleObject(name = "bad-pincode", summary = "Five digits (400)", value = BAD_PINCODE)}))
    @ApiResponse(responseCode = "200", description = "The quote.", content = @Content(mediaType = "application/json",
            schema = @Schema(implementation = Quote.class), examples = @ExampleObject(name = "parcel", value = PARCEL_QUOTE)))
    @ApiResponse(responseCode = "400", description = "A field is missing, of the wrong type or out of range.", content = @Content(mediaType = "application/problem+json",
            schema = @Schema(implementation = ProblemDetail.class), examples = @ExampleObject(name = "bad-pincode",
            value = "{\"title\": \"Bad Request\", \"status\": 400, \"detail\": \"Invalid request content.\", \"instance\": \"/rate-quotes\"}")))
    @ApiResponse(responseCode = "422", description = "Valid, but the network cannot carry it: too heavy, or a PIN code not served.", content = @Content(mediaType = "application/problem+json",
            schema = @Schema(implementation = ProblemDetail.class), examples = @ExampleObject(name = "too-heavy",
            value = "{\"title\": \"Unprocessable Content\", \"status\": 422, \"detail\": \"Parcels above 50000 g cannot be carried\", \"instance\": \"/rate-quotes\"}")))
    @PostMapping("/rate-quotes")
    Quote quote(@Valid @RequestBody QuoteRequest r) {
        if (r.weightGrams() > RateCard.MAX_WEIGHT_GRAMS) {
            throw unprocessable("Parcels above " + RateCard.MAX_WEIGHT_GRAMS + " g cannot be carried");
        }
        if (RateCard.NOT_SERVED.contains(r.fromPincode()) || RateCard.NOT_SERVED.contains(r.toPincode())) {
            throw unprocessable("This PIN code is not served yet");
        }
        RateCard.Zone zone = RateCard.zone(r.fromPincode(), r.toPincode());
        long chargeable = Math.max(r.weightGrams(), RateCard.volumetricGrams(r.lengthCm(), r.widthCm(), r.heightCm()));
        long price = RateCard.pricePaise(zone, r.service(), chargeable);
        long gst = RateCard.gstPaise(price);
        return new Quote("Q-" + quotes.incrementAndGet(), zone, chargeable, price, gst, price + gst, RateCard.days(zone, r.service()));
    }

    private static ErrorResponseException unprocessable(String detail) {
        return new ErrorResponseException(HttpStatus.UNPROCESSABLE_CONTENT, ProblemDetail.forStatusAndDetail(HttpStatus.UNPROCESSABLE_CONTENT, detail), null);
    }
}

package com.dakroute.rates;

import org.springframework.stereotype.Component;

import java.util.Set;

/**
 * Demo rules, not Dakroute's real tariff. Zone by PIN code: the same first three digits is LOCAL, the same first two
 * REGIONAL, anything else NATIONAL. Price per started 500 g of chargeable weight; EXPRESS costs half as much again.
 * Chargeable weight is the larger of the actual weight and the volumetric weight (length x width x height in cm / 5,
 * in grams, the common 5000 divisor). GST 18%, rounded to the nearest paisa.
 */
@Component
class RateCard {

    enum Zone { LOCAL, REGIONAL, NATIONAL }

    enum Service { STANDARD, EXPRESS }

    static final int MAX_WEIGHT_GRAMS = 50_000;
    /** Demo rule: PIN codes this network does not serve yet. */
    static final Set<String> NOT_SERVED = Set.of("744101", "194101");

    static Zone zone(String from, String to) {
        return from.regionMatches(0, to, 0, 3) ? Zone.LOCAL : from.regionMatches(0, to, 0, 2) ? Zone.REGIONAL : Zone.NATIONAL;
    }

    static long volumetricGrams(int lengthCm, int widthCm, int heightCm) {
        return (long) lengthCm * widthCm * heightCm / 5;
    }

    static long pricePaise(Zone zone, Service service, long chargeableGrams) {
        long perSlab = switch (zone) {
            case LOCAL -> 4000;
            case REGIONAL -> 5500;
            case NATIONAL -> 7500;
        };
        long slabs = (chargeableGrams + 499) / 500;
        long price = perSlab * slabs;
        return service == Service.EXPRESS ? price * 3 / 2 : price;
    }

    static long gstPaise(long pricePaise) {
        return (pricePaise * 18 + 50) / 100;
    }

    static int days(Zone zone, Service service) {
        return switch (zone) {
            case LOCAL -> 1;
            case REGIONAL -> service == Service.EXPRESS ? 2 : 3;
            case NATIONAL -> service == Service.EXPRESS ? 3 : 5;
        };
    }
}

package com.dakroute.rates;

import org.junit.jupiter.api.Test;
import org.springframework.mock.web.MockHttpServletResponse;
import tools.jackson.databind.JsonNode;
import tools.jackson.databind.node.ObjectNode;

import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;

import static org.assertj.core.api.Assertions.assertThat;
import static org.skyscreamer.jsonassert.JSONAssert.assertEquals;

/**
 * The docs are tested against the API, so they cannot drift: every example is sent, every documented answer is
 * compared with the real one, every field the docs call required is refused when missing, and any change to the
 * description shows as a diff against the approved copy, for review.
 */
class OpenApiDocsTest extends ApiTest {

    JsonNode operation() throws Exception {
        return spec().at("/paths/~1rate-quotes/post");
    }

    /** The status whose documented example has the same name as a request example; 200 if none does. */
    static int documentedStatus(JsonNode op, String example) {
        for (Map.Entry<String, JsonNode> r : op.get("responses").properties()) {
            for (JsonNode content : r.getValue().path("content")) {
                if (content.path("examples").has(example)) {
                    return Integer.parseInt(r.getKey());
                }
            }
        }
        return 200;
    }

    @Test
    void everyRequestExampleGetsTheStatusTheDocsGiveIt() throws Exception {
        JsonNode op = operation();
        JsonNode examples = op.at("/requestBody/content/application~1json/examples");
        assertThat(examples.propertyNames()).hasSizeGreaterThanOrEqualTo(4);
        for (Map.Entry<String, JsonNode> ex : examples.properties()) {
            MockHttpServletResponse real = quoteResponse(ex.getValue().get("value").toString());
            assertThat(real.getStatus()).as(ex.getKey()).isEqualTo(documentedStatus(op, ex.getKey()));
        }
    }

    @Test
    void everyDocumentedAnswerMatchesTheRealOne() throws Exception {
        JsonNode op = operation();
        JsonNode requests = op.at("/requestBody/content/application~1json/examples");
        for (Map.Entry<String, JsonNode> r : op.get("responses").properties()) {
            for (JsonNode content : r.getValue().path("content")) {
                for (Map.Entry<String, JsonNode> ex : content.path("examples").properties()) {
                    MockHttpServletResponse real = quoteResponse(requests.get(ex.getKey()).get("value").toString());
                    JsonNode documented = ((ObjectNode) ex.getValue().get("value").deepCopy()).remove(List.of("quoteId"));
                    assertEquals(documented.toString(), real.getContentAsString(), false);   // every documented field, with its value
                }
            }
        }
    }

    @Test
    void theFieldsTheDocsCallRequiredAreExactlyTheOnesTheApiRefusesWithout() throws Exception {
        JsonNode schema = spec().at("/components/schemas/QuoteRequest");
        List<String> required = new ArrayList<>();
        schema.get("required").forEach(n -> required.add(n.asString()));
        ObjectNode parcel = (ObjectNode) JSON.readTree(RateQuoteController.PARCEL);
        for (String field : schema.get("properties").propertyNames()) {
            ObjectNode without = parcel.deepCopy();
            without.remove(field);
            int status = quoteResponse(without.toString()).getStatus();
            assertThat(status == 400).as(field + " missing gave " + status + "; docs say required: " + required.contains(field)).isEqualTo(required.contains(field));
        }
    }

    @Test
    void theDescriptionMatchesTheApprovedCopy() throws Exception {
        String generated = JSON.writerWithDefaultPrettyPrinter().writeValueAsString(spec());
        Path approved = Path.of("src/test/resources/openapi/approved.json");
        if (!Files.exists(approved) || !JSON.readTree(Files.readString(approved)).equals(JSON.readTree(generated))) {
            Files.createDirectories(Path.of("target"));
            Files.writeString(Path.of("target/openapi-generated.json"), generated);   // review the diff, then copy it over approved.json
        }
        assertThat(JSON.readTree(Files.readString(approved))).isEqualTo(JSON.readTree(generated));
    }
}

    }

    @Test
    void aNationalParcelIsPricedBySlabWithGst() throws Exception {
        quote(parcel("560001", "110001", 1200, 30, 20, 10, "STANDARD")).andExpect(status().isOk()).andExpect(content().json("""
                {"zone":"NATIONAL","chargeableWeightGrams":1200,"pricePaise":22500,"gstPaise":4050,"totalPaise":26550,"estimatedDays":5}"""));
    }

    @Test
    void zonesVolumetricWeightAndExpress() throws Exception {
        quote(parcel("560001", "560034", 800, 60, 40, 40, "EXPRESS")).andExpect(content().json("""
                {"zone":"LOCAL","chargeableWeightGrams":19200,"pricePaise":234000,"gstPaise":42120,"totalPaise":276120,"estimatedDays":1}"""));
        quote(parcel("560001", "563101", 500, 10, 10, 10, "STANDARD")).andExpect(jsonPath("$.zone").value("REGIONAL")).andExpect(jsonPath("$.pricePaise").value(5500));

    }

        assertThat(RateCard.gstPaise(1001)).isEqualTo(180);   // 180.18
        assertThat(RateCard.gstPaise(1003)).isEqualTo(181);   // 180.54

package com.dakroute.rates;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc;
import org.springframework.http.MediaType;
import org.springframework.mock.web.MockHttpServletResponse;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.test.web.servlet.ResultActions;
import tools.jackson.databind.JsonNode;
import tools.jackson.databind.json.JsonMapper;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;

/** Shared setup: the whole app, request helpers, and the generated OpenAPI description. */
@SpringBootTest
@AutoConfigureMockMvc
abstract class ApiTest {

    static final JsonMapper JSON = JsonMapper.builder().build();

    @Autowired
    MockMvc mvc;

    ResultActions quote(String json) throws Exception {
        return mvc.perform(post("/rate-quotes").contentType(MediaType.APPLICATION_JSON).content(json));
    }

    MockHttpServletResponse quoteResponse(String json) throws Exception {
        return quote(json).andReturn().getResponse();
    }

    JsonNode spec() throws Exception {
        return JSON.readTree(mvc.perform(get("/v3/api-docs")).andReturn().getResponse().getContentAsString());
    }
}

Interview takeaways

Code first or design first?

Code first generates the description from the code, so it follows the code; design first agrees the contract before coding. Either way, test the description against the running API.

Where do field limits in the docs come from?

springdoc reads the Bean Validation annotations (pattern, min, max, not null) and @Schema; anything it cannot know, such as Jackson refusing a missing int, must be added.

How do you stop docs from drifting?

Generate them, send every example in a test, compare documented answers with real ones, and review the description's diff on every change.

Why document errors?

Partners spend most of their integration time on errors. Each error needs its status, when it happens and an example.

What is contract review?

Looking at the change to the API description in the pull request, before it ships, to catch breaking or accidental changes.
