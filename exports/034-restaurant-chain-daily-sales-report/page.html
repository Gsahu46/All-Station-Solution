The problem in real life

  1. Every morning, a spreadsheet

    Someone copies 40 outlets' till totals into a sheet by hand. It takes an hour, and a typo once doubled an outlet's sales.

  2. The first program is a little wrong

    It adds rupees as double, so ₹293.90 becomes ₹293.89. It also reuses one key object while grouping, and every row comes out labelled with the last bill's outlet and hour.

  3. The fix

    Group with immutable keys, add exact decimals, convert to paise once, and count the day from midnight in India.

Money adds up exactly or not at all, and a key must never change once it is in a map.

What are we building?

GET /reports/daily-sales?date=… gives one day's sales for the whole chain: each outlet's total, number of bills and busiest hour, highest first, and the chain's total per hour.

An everyday analogy

A cashier closing the day: receipts sorted into one envelope per counter, each envelope added up in rupees and paise, envelopes ranked by total. Nobody re-labels an envelope after it is filed.

How it works in 4 steps

  1. Find the day's bills: from midnight to midnight in India.
  2. Group them by outlet, by hour, and by outlet and hour.
  3. Add up each group exactly, and count the bills.
  4. Sort and convert: outlets highest first, amounts to whole paise.
Check yourself: why is a bill at 00:05 on the 14th in India not on the 13th's report, although the server's clock still says the 13th?

The server runs in UTC, five and a half hours behind India. The outlet's day, and the owner's report, follow India's midnight.

What this station is not

  • No database. Seven days of generated bills in memory.
  • No refunds or taxes split out. A bill's amount is what the till printed.
  • No live day. Reports are for days that are over.

Business problem

Tiffino (a fictional restaurant chain) has 40 outlets. Owners get daily totals per outlet and per hour from a spreadsheet someone fills by hand.

Acceptance criteria

On a small test day whose totals can be checked by hand (Fixture).

  1. Given bills of ₹261.45, ₹157.40 and ₹524.95 at TF-01, then its total is exactly 94,380 paise.
  2. Given ₹188.95 and ₹104.95 at TF-02, then 29,390 paise, not 29,389.
  3. Given a bill at 00:05 India time on the 14th and one at 00:10 on the 15th, then the first is on the 14th's report and the second is not.
  4. Given two outlets with equal totals, then the lower outlet id first; two hours with equal sales, then the earlier hour is the busiest.
  5. Given a day with no bills, 404; today or a future day, 422; a missing or malformed date, 400.

Requirements

  • Amounts are summed exactly (BigDecimal) and returned as integer paise.
  • Group keys are immutable: String, Integer, or a record.
  • The day and the hours are India's (Asia/Kolkata).
  • A bill with a fraction of a paisa is an error, not something to round quietly.

Learning objectives

  • Group and total with Collectors.groupingBy and reducing.
  • Sum BigDecimal with reduce, and know why double is wrong for money.
  • Sort map entries by value, then by key.
  • Compare a stream with a loop, and choose for readability.

The trap

Plausible but wrong

Summing money in double, and grouping by a mutable key.

The first test shows (188.95 + 104.95) * 100 is 29389.999999999996 in double, so the old report gave TF-02 29,389 paise for 29,390 of bills. The second shows the reused key: the map has several entries, and every one reads "TF-03 20", the last bill's outlet and hour, because they are all the same object. The third shows the real report's exact, correctly labelled rows. While building, each fix was undone once. Hours in UTC turned 2 tests red, and a UTC day 4. Ascending order turned 3 red, and a double sum 11 (the paise conversion refuses the drift). Ties going to the later hour turned 1 red, and allowing today's report 1.

class DoubleMoneyMutableKeyTrapTest {

    static final List<Sale> DAY = Fixture.FEED.between(Fixture.DAY.atStartOfDay(DailySalesReport.INDIA).toInstant(),
            Fixture.DAY.plusDays(1).atStartOfDay(DailySalesReport.INDIA).toInstant());

package com.tiffino.reports;

import java.time.ZoneId;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Objects;

/** The report as the spreadsheet macro's replacement first did it, kept only in tests. */
final class OldDailyReport {

    /** A mutable key: equals and hashCode read fields that the loop below keeps changing. */
    static final class OutletHourKey {
        String outlet;
        int hour;

        @Override
        public boolean equals(Object o) {
            return o instanceof OutletHourKey k && k.hour == hour && Objects.equals(k.outlet, outlet);
        }

        @Override
        public int hashCode() {
            return Objects.hash(outlet, hour);
        }
    }

    private OldDailyReport() {
    }

    static Map<OutletHourKey, Double> byOutletHour(List<Sale> sales) {
        Map<OutletHourKey, Double> totals = new HashMap<>();
        OutletHourKey key = new OutletHourKey();   // one object, reused "to save allocations"
        for (Sale s : sales) {
            key.outlet = s.outletId();
            key.hour = s.at().atZone(ZoneId.of("Asia/Kolkata")).getHour();
            totals.merge(key, s.amountRupees().doubleValue(), Double::sum);
        }
        return totals;
    }

    static long outletTotalPaise(List<Sale> sales, String outletId) {
        double rupees = 0;
        for (Sale s : sales) {
            if (s.outletId().equals(outletId)) {
                rupees += s.amountRupees().doubleValue();
            }
        }
        return (long) (rupees * 100);   // 293.9 * 100 is 29389.999999999996 in double
    }
}

package com.tiffino.reports;

import org.springframework.format.annotation.DateTimeFormat;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import java.time.LocalDate;

@RestController
class ReportController {

    private final DailySalesReport report;

    ReportController(DailySalesReport report) {
        this.report = report;
    }

    /** ?date=2026-10-14 (ISO). Missing or malformed is a 400 from Spring. */
    @GetMapping("/reports/daily-sales")
    DailySalesReport.Report dailySales(@RequestParam @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate date) {
        return report.forDay(date);
    }
}

src/main/java/com/tiffino/reports/DailySalesReport.java

Does
Finds the day's bills and groups, totals, sorts and converts them.
Why
Three groupingBy calls into an immutable Totals record; the composite key is a record; paise once, at the end.

  • Sorting entries: comparingByValue(...).reversed().thenComparing(comparingByKey()).
  • longValueExact() throws rather than rounding a fraction of a paisa.
package com.tiffino.reports;

import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.stereotype.Service;
import org.springframework.web.ErrorResponseException;

import java.math.BigDecimal;
import java.time.Clock;
import java.time.Instant;
import java.time.LocalDate;
import java.time.ZoneId;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

import static java.util.stream.Collectors.groupingBy;
import static java.util.stream.Collectors.reducing;

/**
 * One day's sales, per outlet and per hour, in India's day (midnight to midnight IST). Amounts are summed as
 * BigDecimal, exactly, and turned into paise once, at the end. Keys are immutable (String, Integer, a record).
 */
@Service
class DailySalesReport {

    static final ZoneId INDIA = ZoneId.of("Asia/Kolkata");

    /** A running total: an immutable value, combined with plus. */
    record Totals(BigDecimal amount, long bills) {
        static final Totals ZERO = new Totals(BigDecimal.ZERO, 0);

        static Totals of(Sale s) {
            return new Totals(s.amountRupees(), 1);
        }

        Totals plus(Totals other) {
            return new Totals(amount.add(other.amount), bills + other.bills);
        }

        long paise() {
            return amount.movePointRight(2).longValueExact();   // throws if a till ever sends a fraction of a paisa
        }
    }

    /** A composite key: a record, so equals and hashCode come from fields that can never change. */
    record OutletHour(String outletId, int hour) {
    }

    record OutletRow(String outletId, String name, long totalPaise, long bills, int busiestHour) {
    }

    record HourRow(int hour, long totalPaise, long bills) {
    }

    record Report(LocalDate date, long chainTotalPaise, long bills, List<OutletRow> outlets, List<HourRow> hours) {
    }

    private final SalesFeed feed;
    private final Outlets outlets;
    private final Clock clock;

    DailySalesReport(SalesFeed feed, Outlets outlets, Clock clock) {
        this.feed = feed;
        this.outlets = outlets;
        this.clock = clock;
    }

    static LocalDate today(Clock clock) {
        return LocalDate.now(clock.withZone(INDIA));
    }

    Report forDay(LocalDate date) {
        if (!date.isBefore(today(clock))) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Day not over", date + " has not ended in India yet; reports are for past days.");
        }
        Instant from = date.atStartOfDay(INDIA).toInstant();
        Instant to = date.plusDays(1).atStartOfDay(INDIA).toInstant();
        List<Sale> sales = feed.between(from, to);
        if (sales.isEmpty()) {
            throw problem(HttpStatus.NOT_FOUND, "No sales", "No sales were recorded on " + date + ".");
        }

        Map<String, Totals> byOutlet = sales.stream()
                .collect(groupingBy(Sale::outletId, reducing(Totals.ZERO, Totals::of, Totals::plus)));
        Map<Integer, Totals> byHour = sales.stream()
                .collect(groupingBy(s -> s.at().atZone(INDIA).getHour(), TreeMap::new, reducing(Totals.ZERO, Totals::of, Totals::plus)));
        Map<OutletHour, Totals> byOutletHour = sales.stream()
                .collect(groupingBy(s -> new OutletHour(s.outletId(), s.at().atZone(INDIA).getHour()), reducing(Totals.ZERO, Totals::of, Totals::plus)));
        Totals chain = byOutlet.values().stream().reduce(Totals.ZERO, Totals::plus);

        List<OutletRow> outletRows = byOutlet.entrySet().stream()
                .sorted(Map.Entry.<String, Totals>comparingByValue(Comparator.comparing(Totals::amount)).reversed()
                        .thenComparing(Map.Entry.<String, Totals>comparingByKey()))   // highest first; equal totals by outlet id
                .map(e -> new OutletRow(e.getKey(), outlets.name(e.getKey()), e.getValue().paise(), e.getValue().bills(),
                        busiestHour(byOutletHour, e.getKey())))
                .toList();
        List<HourRow> hourRows = byHour.entrySet().stream()
                .map(e -> new HourRow(e.getKey(), e.getValue().paise(), e.getValue().bills()))
                .toList();
        return new Report(date, chain.paise(), chain.bills(), outletRows, hourRows);
    }

    /** The outlet's hour with the highest sales; on a tie, the earlier hour. */
    static int busiestHour(Map<OutletHour, Totals> byOutletHour, String outletId) {
        return byOutletHour.entrySet().stream()
                .filter(e -> e.getKey().outletId().equals(outletId))
                .max(Comparator.<Map.Entry<OutletHour, Totals>, BigDecimal>comparing(e -> e.getValue().amount())
                        .thenComparing(e -> -e.getKey().hour()))
                .orElseThrow()
                .getKey().hour();
    }

    private static ErrorResponseException problem(HttpStatus status, String title, String detail) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(status, detail);
        p.setTitle(title);
        return new ErrorResponseException(status, p, null);
    }
}

/**
 * Demo sales for the 7 days before today, generated at startup with fixed seeds, so a given day's report reads the
 * same whenever the app is started. Menu prices plus 5% GST, rounded to the paisa, as a till would print them.
 */
@Component
class DemoSalesFeed implements SalesFeed {

    private static final int[] MENU = {89, 129, 149, 179, 199, 249, 299, 349};
    private static final BigDecimal WITH_GST = new BigDecimal("1.05");

    private final List<Sale> sales = new ArrayList<>();

    DemoSalesFeed(Clock clock, Outlets outlets) {
        LocalDate today = DailySalesReport.today(clock);
        for (int daysAgo = 1; daysAgo <= 7; daysAgo++) {
            Random random = new Random(1_000L + daysAgo);   // same seed for "yesterday" every time
            LocalDate day = today.minusDays(daysAgo);
            for (String outlet : outlets.ids()) {
                int bills = 20 + random.nextInt(30);
                for (int b = 0; b < bills; b++) {
                    Instant at = day.atTime(8 + random.nextInt(15), random.nextInt(60)).atZone(DailySalesReport.INDIA).toInstant();
                    int items = 1 + random.nextInt(3);
                    int rupees = 0;
                    for (int i = 0; i < items; i++) {
                        rupees += MENU[random.nextInt(MENU.length)];
                    }
                    sales.add(new Sale(outlet, at, BigDecimal.valueOf(rupees).multiply(WITH_GST).setScale(2, RoundingMode.HALF_UP)));
                }
            }
        }
        sales.sort(Comparator.comparing(Sale::at));
    }

    @Override
    public List<Sale> between(Instant from, Instant to) {
        return sales.stream().filter(s -> !s.at().isBefore(from) && s.at().isBefore(to)).toList();
    }

        OutletHourKey key = new OutletHourKey();   // one object, reused "to save allocations"
        for (Sale s : sales) {
            key.outlet = s.outletId();
            key.hour = s.at().atZone(ZoneId.of("Asia/Kolkata")).getHour();
            totals.merge(key, s.amountRupees().doubleValue(), Double::sum);
        }
        return totals;
    }

    static long outletTotalPaise(List<Sale> sales, String outletId) {
        double rupees = 0;
        for (Sale s : sales) {
            if (s.outletId().equals(outletId)) {
                rupees += s.amountRupees().doubleValue();
            }
        }
        return (long) (rupees * 100);   // 293.9 * 100 is 29389.999999999996 in double
    }

package com.tiffino.reports;

import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.stereotype.Service;
import org.springframework.web.ErrorResponseException;

import java.math.BigDecimal;
import java.time.Clock;
import java.time.Instant;
import java.time.LocalDate;
import java.time.ZoneId;
import java.util.Comparator;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

import static java.util.stream.Collectors.groupingBy;
import static java.util.stream.Collectors.reducing;

/**
 * One day's sales, per outlet and per hour, in India's day (midnight to midnight IST). Amounts are summed as
 * BigDecimal, exactly, and turned into paise once, at the end. Keys are immutable (String, Integer, a record).
 */
@Service
class DailySalesReport {

    static final ZoneId INDIA = ZoneId.of("Asia/Kolkata");

    /** A running total: an immutable value, combined with plus. */
    record Totals(BigDecimal amount, long bills) {
        static final Totals ZERO = new Totals(BigDecimal.ZERO, 0);

        static Totals of(Sale s) {
            return new Totals(s.amountRupees(), 1);
        }

        Totals plus(Totals other) {
            return new Totals(amount.add(other.amount), bills + other.bills);
        }

        long paise() {
            return amount.movePointRight(2).longValueExact();   // throws if a till ever sends a fraction of a paisa
        }
    }

    /** A composite key: a record, so equals and hashCode come from fields that can never change. */
    record OutletHour(String outletId, int hour) {
    }

    record OutletRow(String outletId, String name, long totalPaise, long bills, int busiestHour) {
    }

    record HourRow(int hour, long totalPaise, long bills) {
    }

    record Report(LocalDate date, long chainTotalPaise, long bills, List<OutletRow> outlets, List<HourRow> hours) {
    }

    private final SalesFeed feed;
    private final Outlets outlets;
    private final Clock clock;

    DailySalesReport(SalesFeed feed, Outlets outlets, Clock clock) {
        this.feed = feed;
        this.outlets = outlets;
        this.clock = clock;
    }

    static LocalDate today(Clock clock) {
        return LocalDate.now(clock.withZone(INDIA));
    }

    Report forDay(LocalDate date) {
        if (!date.isBefore(today(clock))) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Day not over", date + " has not ended in India yet; reports are for past days.");
        }
        Instant from = date.atStartOfDay(INDIA).toInstant();
        Instant to = date.plusDays(1).atStartOfDay(INDIA).toInstant();
        List<Sale> sales = feed.between(from, to);
        if (sales.isEmpty()) {
            throw problem(HttpStatus.NOT_FOUND, "No sales", "No sales were recorded on " + date + ".");
        }

        Map<String, Totals> byOutlet = sales.stream()
                .collect(groupingBy(Sale::outletId, reducing(Totals.ZERO, Totals::of, Totals::plus)));
        Map<Integer, Totals> byHour = sales.stream()
                .collect(groupingBy(s -> s.at().atZone(INDIA).getHour(), TreeMap::new, reducing(Totals.ZERO, Totals::of, Totals::plus)));
        Map<OutletHour, Totals> byOutletHour = sales.stream()
                .collect(groupingBy(s -> new OutletHour(s.outletId(), s.at().atZone(INDIA).getHour()), reducing(Totals.ZERO, Totals::of, Totals::plus)));
        Totals chain = byOutlet.values().stream().reduce(Totals.ZERO, Totals::plus);

        List<OutletRow> outletRows = byOutlet.entrySet().stream()
                .sorted(Map.Entry.<String, Totals>comparingByValue(Comparator.comparing(Totals::amount)).reversed()
                        .thenComparing(Map.Entry.<String, Totals>comparingByKey()))   // highest first; equal totals by outlet id
                .map(e -> new OutletRow(e.getKey(), outlets.name(e.getKey()), e.getValue().paise(), e.getValue().bills(),
                        busiestHour(byOutletHour, e.getKey())))
                .toList();
        List<HourRow> hourRows = byHour.entrySet().stream()
                .map(e -> new HourRow(e.getKey(), e.getValue().paise(), e.getValue().bills()))
                .toList();
        return new Report(date, chain.paise(), chain.bills(), outletRows, hourRows);
    }

    /** Each outlet's total for the 7 India days ending on lastDay, highest first. */
    Map<String, Long> weekTotals(LocalDate lastDay) {
        if (!lastDay.isBefore(today(clock))) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Day not over", lastDay + " has not ended in India yet; reports are for past days.");
        }
        Instant from = lastDay.minusDays(6).atStartOfDay(INDIA).toInstant();
        Instant to = lastDay.plusDays(1).atStartOfDay(INDIA).toInstant();
        Map<String, Totals> byOutlet = feed.between(from, to).stream()
                .collect(groupingBy(Sale::outletId, reducing(Totals.ZERO, Totals::of, Totals::plus)));
        return byOutlet.entrySet().stream()
                .sorted(Map.Entry.<String, Totals>comparingByValue(Comparator.comparing(Totals::amount)).reversed()
                        .thenComparing(Map.Entry.<String, Totals>comparingByKey()))
                .collect(LinkedHashMap::new, (m, e) -> m.put(e.getKey(), e.getValue().paise()), Map::putAll);
    }

    /** For each city, the hour with the highest sales across its outlets; on a tie, the earlier hour. */
    Map<String, Integer> busiestHourByCity(LocalDate date) {
        Instant from = date.atStartOfDay(INDIA).toInstant();
        Instant to = date.plusDays(1).atStartOfDay(INDIA).toInstant();
        Map<String, Map<Integer, Totals>> byCityHour = feed.between(from, to).stream()
                .collect(groupingBy(s -> outlets.city(s.outletId()),
                        groupingBy(s -> s.at().atZone(INDIA).getHour(), reducing(Totals.ZERO, Totals::of, Totals::plus))));
        Map<String, Integer> peaks = new TreeMap<>();
        byCityHour.forEach((city, hours) -> peaks.put(city, hours.entrySet().stream()
                .max(Comparator.<Map.Entry<Integer, Totals>, BigDecimal>comparing(e -> e.getValue().amount()).thenComparing(e -> -e.getKey()))
                .orElseThrow().getKey()));
        return peaks;
    }

    /** The outlet's hour with the highest sales; on a tie, the earlier hour. */
    static int busiestHour(Map<OutletHour, Totals> byOutletHour, String outletId) {
        return byOutletHour.entrySet().stream()
                .filter(e -> e.getKey().outletId().equals(outletId))
                .max(Comparator.<Map.Entry<OutletHour, Totals>, BigDecimal>comparing(e -> e.getValue().amount())
                        .thenComparing(e -> -e.getKey().hour()))
                .orElseThrow()
                .getKey().hour();
    }

    private static ErrorResponseException problem(HttpStatus status, String title, String detail) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(status, detail);
        p.setTitle(title);
        return new ErrorResponseException(status, p, null);
    }

Interview takeaways

Why not use double for money?

double is binary floating point; most decimal amounts like 0.1 or 188.95 cannot be stored exactly, and the errors show up after additions or when converting to paise. Use BigDecimal or integer minor units.

What happens if you mutate an object used as a HashMap key?

Its hashCode changes, so the map looks in the wrong bucket: lookups fail and entries can be duplicated. Keys must be immutable; records with final fields are ideal.

How do you sum BigDecimal in a stream?

map to the amount, then reduce(BigDecimal.ZERO, BigDecimal::add). Inside groupingBy, use reducing(BigDecimal.ZERO, mapper, BigDecimal::add).

How do you sort a map by value?

Stream its entrySet and sort with Map.Entry.comparingByValue(), reversed for highest first, thenComparing(comparingByKey()) to make ties stable.

Streams or loops?

Whichever reads more clearly. Streams suit grouping, mapping and sorting pipelines; loops suit early exit and complex state. Performance is rarely the deciding factor at this size.
