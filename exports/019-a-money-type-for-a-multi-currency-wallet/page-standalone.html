Level 1, about 5 minutes. Plain language: no code.

The problem in real life

  1. Asha gets ₹100 of cashback and a $5 refund

    The wallet shows a balance of 105. Of what? The app treats it as rupees.

  2. A reconciliation check fails

    The ledger says ₹10.5, the bank file says ₹10.50, and the code says they are different amounts, because BigDecimal.equals compares the number of decimals too.

  3. The fix

    A Money type that stores whole minor units with its currency, refuses to add different currencies, and is compared by value. The wallet keeps one balance per currency.

An amount without its currency is not money. Make the type carry both, and compare by value.

What are we building?

POST /wallets/{id}/credits adds an amount in one currency. GET /wallets/{id}/balance shows one balance per currency, each with that currency's own number of decimals.

An everyday analogy

A travel pouch with one pocket per currency. Rupees go in the rupee pocket and dollars in the dollar pocket. Nobody counts them together without first asking at what rate.

How it works in 4 steps

  1. Read the amount as text, like "10.5", with its currency code.
  2. Convert to minor units for that currency: 1,050 paise. Refuse anything that would lose a digit.
  3. Add to that currency's pocket; adding a different currency is an error in the type itself.
  4. Show each pocket with the currency's own decimals: 10.50 INR, 1500 JPY.
Check yourself: is ₹10.5 the same as ₹10.50? Is 10.50 rupees the same as 10.50 dollars?

Yes, then no. Same value in the same currency is the same money, whatever the trailing zeros. The same number in two currencies is two different things.

What this station is not

  • No currency exchange. Balances are never added across currencies (challenge 2 adds an indicative total at demo rates).
  • No debits. Challenge 1 adds them.
  • No database. Two demo wallets live in memory.

Business problem

Tijori (a fictional fintech app) added foreign-currency wallets for travellers. Its wallet keeps one BigDecimal balance, so a dollar refund was added to rupee cashback. Reconciliation compares amounts with equals, so ₹10.5 and ₹10.50 fail to match and land in a manual-review queue.

Acceptance criteria

  1. Given credits of "10.5" and "10.50" INR, then both show as 10.50 and the balance is 21.00.
  2. Given ₹100 and $5 credited, then the balance shows 100.00 INR and 5.00 USD, separately.
  3. Given "1500" JPY, then 1500 with no decimals; "1500.5" JPY or "10.505" INR is 422.
  4. Given an unsupported currency or a zero amount, then 422; a negative or malformed amount, 400.
  5. Given an unknown wallet, then 404.
  6. Given two Money values, then they are equal exactly when the currency and the minor units are equal.

Requirements

  • Amounts arrive as decimal strings; up to 999,999 per credit (a demo rule). Currency codes are normalised with Locale.ROOT.
  • Money is stored as whole minor units with its Currency; conversion to minor units never rounds.
  • Adding different currencies throws; overflow throws instead of wrapping around.
  • Supported currencies (a demo set): INR, USD, AED, JPY.

Learning objectives

  • Write a value object as a record: immutable, compared by value.
  • Explain BigDecimal scale, and why equals and compareTo disagree.
  • Use Currency.getDefaultFractionDigits instead of assuming two decimals.
  • Make the wrong operation (rupees plus dollars) impossible to do quietly.

The trap

Plausible but wrong

Adding amounts in different currencies, or comparing BigDecimal with equals.

The first test shows the old wallet's balance of 105 after ₹100 and $5. The second shows equals calling 10.5 and 10.50 different, and a HashSet keeping both, while two Money values are one. The third shows the wallet keeping separate balances. While building, removing the currency check turned a test red, and so did rounding instead of refusing extra decimals. Keying every balance under INR made the Money type itself refuse the addition: the type caught a bug in the code around it.

package com.tijori.wallets;

import org.junit.jupiter.api.Test;

import java.math.BigDecimal;
import java.util.Currency;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

import static org.assertj.core.api.Assertions.assertThat;
import static org.hamcrest.Matchers.hasSize;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;

/** The first test written for this station: it reproduces the bugs before the fix. */
class RupeesPlusDollarsTrapTest extends ApiTest {

    static final Currency INR = Currency.getInstance("INR");

    /** The "before" wallet: one BigDecimal balance, whatever the currency. Kept only in tests. */
    static BigDecimal oldBalanceAfter(String... amounts) {
        BigDecimal balance = BigDecimal.ZERO;
        for (String a : amounts) {
            balance = balance.add(new BigDecimal(a));
        }
        return balance;
    }

    @Test
    void theOldWalletAddsRupeesToDollars() {
        // Rs 100 and then USD 5: the old balance says "105" of nothing in particular.
        assertThat(oldBalanceAfter("100", "5")).isEqualByComparingTo("105");
    }

    @Test
    void bigDecimalEqualsSeesTenPointFiveAndTenPointFiftyAsDifferent() {
        assertThat(new BigDecimal("10.5").equals(new BigDecimal("10.50"))).isFalse();     // equals compares scale too
        assertThat(new BigDecimal("10.5").compareTo(new BigDecimal("10.50"))).isZero();   // compareTo compares value
        Set<BigDecimal> credits = new HashSet<>(List.of(new BigDecimal("10.5"), new BigDecimal("10.50")));
        assertThat(credits).hasSize(2);   // "two different amounts" in a set, a map key or a duplicate check

        assertThat(Money.parse("10.5", INR)).isEqualTo(Money.parse("10.50", INR));
        assertThat(new HashSet<>(List.of(Money.parse("10.5", INR), Money.parse("10.50", INR)))).hasSize(1);
    }

    @Test
    void theWalletKeepsOneBalancePerCurrency() throws Exception {
        credit("w-asha", "100", "INR");
        credit("w-asha", "5", "USD");
        balance("w-asha")
                .andExpect(jsonPath("$.balances", hasSize(2)))
                .andExpect(jsonPath("$.balances[0].amount").value("100.00"))
                .andExpect(jsonPath("$.balances[0].currency").value("INR"))
                .andExpect(jsonPath("$.balances[1].amount").value("5.00"))
                .andExpect(jsonPath("$.balances[1].currency").value("USD"));
    }
}

package com.tijori.wallets;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Pattern;
import jakarta.validation.constraints.Size;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestController;

import java.util.Comparator;
import java.util.Currency;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;

@RestController
class WalletController {

    /** Currencies this demo wallet holds. JPY is here to show a currency with no minor unit. */
    static final Set<String> SUPPORTED = Set.of("INR", "USD", "AED", "JPY");

    /** The amount is a string: a JSON number can pass through a double in some clients and arrive as 10.499999. */
    record CreditRequest(@NotNull @Pattern(regexp = "\\d{1,6}(\\.\\d{1,4})?", message = "must be a decimal string like \"10.50\", at most 999999 (a demo rule)") String amount,
                         @NotNull @Pattern(regexp = "[A-Za-z]{3}", message = "must be a 3-letter ISO 4217 code") String currency,
                         @NotNull @Size(min = 1, max = 40) String reference) {
    }

    record Credited(String walletId, String reference, Money credited, Money balance) {
    }

    record Balances(String walletId, List<Money> balances) {
    }

    /** Two demo wallets, each a balance per currency. Gone when the app stops. */
    private final Map<String, Map<Currency, Money>> wallets = Map.of(
            "w-asha", new ConcurrentHashMap<>(), "w-ravi", new ConcurrentHashMap<>());

    @PostMapping("/wallets/{id}/credits")
    @ResponseStatus(HttpStatus.CREATED)
    Credited credit(@PathVariable String id, @Valid @RequestBody CreditRequest r) {
        String walletId = id.toLowerCase(Locale.ROOT);
        Map<Currency, Money> wallet = wallet(walletId);
        String code = r.currency().toUpperCase(Locale.ROOT);
        if (!SUPPORTED.contains(code)) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Currency not supported",
                    "This wallet holds " + String.join(", ", SUPPORTED.stream().sorted().toList()) + ", not " + code + ".");
        }
        Currency currency = Currency.getInstance(code);
        Money credit;
        try {
            credit = Money.parse(r.amount(), currency);
        } catch (ArithmeticException tooPrecise) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Too many decimal places",
                    code + " amounts have " + currency.getDefaultFractionDigits() + " decimal places; " + r.amount() + " has more.");
        }
        if (credit.minorUnits() == 0) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Nothing to credit", "The amount must be more than zero.");
        }
        Money balance = wallet.merge(currency, credit, Money::plus);   // atomic per currency in a ConcurrentHashMap
        return new Credited(walletId, r.reference(), credit, balance);
    }

    /** One balance per currency, never added together: there is no exchange rate in this station. */
    @GetMapping("/wallets/{id}/balance")
    Balances balance(@PathVariable String id) {
        String walletId = id.toLowerCase(Locale.ROOT);
        return new Balances(walletId, wallet(walletId).values().stream()
                .sorted(Comparator.comparing(m -> m.currency().getCurrencyCode())).toList());
    }

    private Map<Currency, Money> wallet(String id) {
        Map<Currency, Money> wallet = wallets.get(id);
        if (wallet == null) {
            throw problem(HttpStatus.NOT_FOUND, "Wallet not found", "No wallet has the id " + id + ".");
        }
        return wallet;
    }

    /** Empties every wallet. Used by the tests, so each starts from zero. */
    void clear() {
        wallets.values().forEach(Map::clear);
    }

    private static ErrorResponseException problem(HttpStatus status, String title, String detail) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(status, detail);
        p.setTitle(title);
        return new ErrorResponseException(status, p, null);
    }
}

src/main/java/com/tijori/wallets/Money.java

Does
The value object: minor units and a currency.
Why
A record gives value equality for free; the compact constructor and methods keep it correct.
Without it
The trap: amounts without currencies, compared with equals.
  • setScale(digits) with no rounding mode throws if a digit would be lost.
  • plus checks the currency and uses Math.addExact.
  • amount() formats with the currency's own decimals.
package com.tijori.wallets;

import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.annotation.JsonPropertyOrder;

import java.math.BigDecimal;
import java.util.Currency;
import java.util.Objects;

/**
 * An amount in one currency, as a value object: immutable, compared by value. Stored as whole minor units
 * (paise, cents; yen have none), so 10.5 and 10.50 rupees are the same 1,050 paise and the same Money.
 */
@JsonPropertyOrder({"amount", "currency", "minorUnits"})
record Money(long minorUnits, Currency currency) {

    Money {
        Objects.requireNonNull(currency, "currency");
    }

    /**
     * "10.5" INR becomes 1,050 paise. setScale without a rounding mode refuses to drop digits, so "10.505" INR
     * or "100.5" JPY throws instead of silently becoming something else.
     */
    static Money parse(String amount, Currency currency) {
        BigDecimal exact = new BigDecimal(amount).setScale(currency.getDefaultFractionDigits());
        return new Money(exact.unscaledValue().longValueExact(), currency);
    }

    /** Adding is only defined within one currency. Rupees plus dollars is a bug, not a number. */
    Money plus(Money other) {
        if (!currency.equals(other.currency)) {
            throw new CurrencyMismatchException(this, other);
        }
        return new Money(Math.addExact(minorUnits, other.minorUnits), currency);
    }

    /** "10.50" for INR, "100" for JPY: always the currency's own number of decimals. */
    @JsonProperty("amount")
    String amount() {
        return BigDecimal.valueOf(minorUnits, currency.getDefaultFractionDigits()).toPlainString();
    }

    @Override
    public String toString() {
        return amount() + " " + currency.getCurrencyCode();
    }

    static final class CurrencyMismatchException extends IllegalArgumentException {
        CurrencyMismatchException(Money a, Money b) {
            super("Cannot combine " + a + " with " + b + ": different currencies.");
        }
    }
}

    static final Currency USD = Currency.getInstance("USD");
    static final Currency JPY = Currency.getInstance("JPY");

    void equalAmountsAreEqualWhateverTheTrailingZeros() {

        Money b = Money.parse("10.50", INR);

        assertThat(a.minorUnits()).isEqualTo(1050);

    }

        assertThat(a.plus(b)).isEqualTo(Money.parse("3", INR));
        assertThat(a).isEqualTo(Money.parse("1", INR));
        assertThat(b).isEqualTo(Money.parse("2", INR));

package com.tijori.wallets;

import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.annotation.JsonPropertyOrder;

import java.math.BigDecimal;
import java.math.MathContext;
import java.math.RoundingMode;
import java.util.Currency;
import java.util.Objects;

/**
 * An amount in one currency, as a value object: immutable, compared by value. Stored as whole minor units
 * (paise, cents; yen have none), so 10.5 and 10.50 rupees are the same 1,050 paise and the same Money.
 */
@JsonPropertyOrder({"amount", "currency", "minorUnits"})
record Money(long minorUnits, Currency currency) {

    Money {
        Objects.requireNonNull(currency, "currency");
    }

    /**
     * "10.5" INR becomes 1,050 paise. setScale without a rounding mode refuses to drop digits, so "10.505" INR
     * or "100.5" JPY throws instead of silently becoming something else.
     */
    static Money parse(String amount, Currency currency) {
        BigDecimal exact = new BigDecimal(amount).setScale(currency.getDefaultFractionDigits());
        return new Money(exact.unscaledValue().longValueExact(), currency);
    }

    /** Adding is only defined within one currency. Rupees plus dollars is a bug, not a number. */
    Money plus(Money other) {
        if (!currency.equals(other.currency)) {
            throw new CurrencyMismatchException(this, other);
        }
        return new Money(Math.addExact(minorUnits, other.minorUnits), currency);
    }

    /** Challenge 1: subtracting, also within one currency only. The caller decides whether a negative result is allowed. */
    Money minus(Money other) {
        return plus(new Money(Math.negateExact(other.minorUnits), other.currency));
    }

    /**
     * Challenge 2: this amount in another currency, given both currencies' rates in a common unit (rupees here).
     * Rounded once, half-even, to the target's decimals. Indicative only: a real conversion is a priced trade.
     */
    Money convertTo(Currency target, BigDecimal rateOfThis, BigDecimal rateOfTarget) {
        BigDecimal value = BigDecimal.valueOf(minorUnits, currency.getDefaultFractionDigits())
                .multiply(rateOfThis, MathContext.DECIMAL64).divide(rateOfTarget, MathContext.DECIMAL64)
                .setScale(target.getDefaultFractionDigits(), RoundingMode.HALF_EVEN);
        return new Money(value.unscaledValue().longValueExact(), target);
    }

    /** "10.50" for INR, "100" for JPY: always the currency's own number of decimals. */
    @JsonProperty("amount")
    String amount() {
        return BigDecimal.valueOf(minorUnits, currency.getDefaultFractionDigits()).toPlainString();
    }

    @Override
    public String toString() {
        return amount() + " " + currency.getCurrencyCode();
    }

    static final class CurrencyMismatchException extends IllegalArgumentException {
        CurrencyMismatchException(Money a, Money b) {
            super("Cannot combine " + a + " with " + b + ": different currencies.");
        }
    }
}

package com.tijori.wallets;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Pattern;
import jakarta.validation.constraints.Size;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestController;

import com.fasterxml.jackson.annotation.JsonInclude;

import java.math.BigDecimal;
import java.util.Comparator;
import java.util.Currency;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;

@RestController
class WalletController {

    /** Currencies this demo wallet holds. JPY is here to show a currency with no minor unit. */
    static final Set<String> SUPPORTED = Set.of("INR", "USD", "AED", "JPY");

    /** The amount is a string: a JSON number can pass through a double in some clients and arrive as 10.499999. */
    record CreditRequest(@NotNull @Pattern(regexp = "\\d{1,6}(\\.\\d{1,4})?", message = "must be a decimal string like \"10.50\", at most 999999 (a demo rule)") String amount,
                         @NotNull @Pattern(regexp = "[A-Za-z]{3}", message = "must be a 3-letter ISO 4217 code") String currency,
                         @NotNull @Size(min = 1, max = 40) String reference) {
    }

    record Credited(String walletId, String reference, Money credited, Money balance) {
    }

    record Debited(String walletId, String reference, Money debited, Money balance) {
    }

    @JsonInclude(JsonInclude.Include.NON_NULL)
    record Balances(String walletId, List<Money> balances, Money indicativeTotal) {
    }

    /** Challenge 2: demo rates in rupees, not market rates. */
    static final Map<String, BigDecimal> DEMO_RATES_IN_INR = Map.of(
            "INR", BigDecimal.ONE, "USD", new BigDecimal("88.00"), "AED", new BigDecimal("24.00"), "JPY", new BigDecimal("0.60"));

    /** Two demo wallets, each a balance per currency. Gone when the app stops. */
    private final Map<String, Map<Currency, Money>> wallets = Map.of(
            "w-asha", new ConcurrentHashMap<>(), "w-ravi", new ConcurrentHashMap<>());

    @PostMapping("/wallets/{id}/credits")
    @ResponseStatus(HttpStatus.CREATED)
    Credited credit(@PathVariable String id, @Valid @RequestBody CreditRequest r) {
        String walletId = id.toLowerCase(Locale.ROOT);
        Map<Currency, Money> wallet = wallet(walletId);
        Money credit = amount(r);
        Money balance = wallet.merge(credit.currency(), credit, Money::plus);   // atomic per currency in a ConcurrentHashMap
        return new Credited(walletId, r.reference(), credit, balance);
    }

    /** Challenge 1: the same body as a credit. compute() is atomic per currency, and throwing inside it changes nothing. */
    @PostMapping("/wallets/{id}/debits")
    @ResponseStatus(HttpStatus.CREATED)
    Debited debit(@PathVariable String id, @Valid @RequestBody CreditRequest r) {
        String walletId = id.toLowerCase(Locale.ROOT);
        Map<Currency, Money> wallet = wallet(walletId);
        Money debit = amount(r);
        Money balance = wallet.compute(debit.currency(), (currency, current) -> {
            if (current == null || current.minorUnits() < debit.minorUnits()) {
                throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Insufficient balance",
                        "The " + currency.getCurrencyCode() + " balance is " + (current == null ? "zero" : current) + "; cannot take " + debit + ".");
            }
            return current.minus(debit);
        });
        return new Debited(walletId, r.reference(), debit, balance);
    }

    private static Money amount(CreditRequest r) {
        Currency currency = supported(r.currency());
        Money money;
        try {
            money = Money.parse(r.amount(), currency);
        } catch (ArithmeticException tooPrecise) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Too many decimal places",
                    currency.getCurrencyCode() + " amounts have " + currency.getDefaultFractionDigits() + " decimal places; " + r.amount() + " has more.");
        }
        if (money.minorUnits() == 0) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Amount is zero", "The amount must be more than zero.");
        }
        return money;
    }

    private static Currency supported(String requested) {
        String code = requested.toUpperCase(Locale.ROOT);
        if (!SUPPORTED.contains(code)) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Currency not supported",
                    "This wallet holds " + String.join(", ", SUPPORTED.stream().sorted().toList()) + ", not " + code + ".");
        }
        return Currency.getInstance(code);
    }

    /** One balance per currency; with ?in=, also an indicative total converted at demo rates (challenge 2). */
    @GetMapping("/wallets/{id}/balance")
    Balances balance(@PathVariable String id, @RequestParam(required = false) String in) {
        String walletId = id.toLowerCase(Locale.ROOT);
        List<Money> balances = wallet(walletId).values().stream()
                .sorted(Comparator.comparing(m -> m.currency().getCurrencyCode())).toList();
        Money total = null;
        if (in != null) {
            Currency target = supported(in);
            total = balances.stream()
                    .map(m -> m.convertTo(target, DEMO_RATES_IN_INR.get(m.currency().getCurrencyCode()), DEMO_RATES_IN_INR.get(target.getCurrencyCode())))
                    .reduce(new Money(0, target), Money::plus);
        }
        return new Balances(walletId, balances, total);
    }

    private Map<Currency, Money> wallet(String id) {
        Map<Currency, Money> wallet = wallets.get(id);
        if (wallet == null) {
            throw problem(HttpStatus.NOT_FOUND, "Wallet not found", "No wallet has the id " + id + ".");
        }
        return wallet;
    }

    /** Empties every wallet. Used by the tests, so each starts from zero. */
    void clear() {
        wallets.values().forEach(Map::clear);
    }

    private static ErrorResponseException problem(HttpStatus status, String title, String detail) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(status, detail);
        p.setTitle(title);
        return new ErrorResponseException(status, p, null);
    }
}

    /** "10.50" for INR, "100" for JPY: always the currency's own number of decimals. */
    @JsonProperty("amount")
    String amount() {
        return BigDecimal.valueOf(minorUnits, currency.getDefaultFractionDigits()).toPlainString();
    }

    @Override
    public String toString() {
        return amount() + " " + currency.getCurrencyCode();
    }

    static final class CurrencyMismatchException extends IllegalArgumentException {
        CurrencyMismatchException(Money a, Money b) {
            super("Cannot combine " + a + " with " + b + ": different currencies.");
        }
    }
}

package com.tijori.wallets;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Pattern;
import jakarta.validation.constraints.Size;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestController;

import com.fasterxml.jackson.annotation.JsonInclude;

import java.math.BigDecimal;
import java.util.Comparator;
import java.util.Currency;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;

@RestController
class WalletController {

    /** Currencies this demo wallet holds. JPY is here to show a currency with no minor unit. */
    static final Set<String> SUPPORTED = Set.of("INR", "USD", "AED", "JPY");

    /** The amount is a string: a JSON number can pass through a double in some clients and arrive as 10.499999. */
    record CreditRequest(@NotNull @Pattern(regexp = "\\d{1,6}(\\.\\d{1,4})?", message = "must be a decimal string like \"10.50\", at most 999999 (a demo rule)") String amount,
                         @NotNull @Pattern(regexp = "[A-Za-z]{3}", message = "must be a 3-letter ISO 4217 code") String currency,
                         @NotNull @Size(min = 1, max = 40) String reference) {
    }

    record Credited(String walletId, String reference, Money credited, Money balance) {
    }

    record Debited(String walletId, String reference, Money debited, Money balance) {
    }

    @JsonInclude(JsonInclude.Include.NON_NULL)
    record Balances(String walletId, List<Money> balances, Money indicativeTotal) {
    }

    /** Challenge 2: demo rates in rupees, not market rates. */
    static final Map<String, BigDecimal> DEMO_RATES_IN_INR = Map.of(
            "INR", BigDecimal.ONE, "USD", new BigDecimal("88.00"), "AED", new BigDecimal("24.00"), "JPY", new BigDecimal("0.60"));

    /** Two demo wallets, each a balance per currency. Gone when the app stops. */
    private final Map<String, Map<Currency, Money>> wallets = Map.of(
            "w-asha", new ConcurrentHashMap<>(), "w-ravi", new ConcurrentHashMap<>());

    @PostMapping("/wallets/{id}/credits")
    @ResponseStatus(HttpStatus.CREATED)
    Credited credit(@PathVariable String id, @Valid @RequestBody CreditRequest r) {
        String walletId = id.toLowerCase(Locale.ROOT);
        Map<Currency, Money> wallet = wallet(walletId);
        Money credit = amount(r);
        Money balance = wallet.merge(credit.currency(), credit, Money::plus);   // atomic per currency in a ConcurrentHashMap
        return new Credited(walletId, r.reference(), credit, balance);
    }

    /** Challenge 1: the same body as a credit. compute() is atomic per currency, and throwing inside it changes nothing. */
    @PostMapping("/wallets/{id}/debits")
    @ResponseStatus(HttpStatus.CREATED)
    Debited debit(@PathVariable String id, @Valid @RequestBody CreditRequest r) {
        String walletId = id.toLowerCase(Locale.ROOT);
        Map<Currency, Money> wallet = wallet(walletId);
        Money debit = amount(r);
        Money balance = wallet.compute(debit.currency(), (currency, current) -> {
            if (current == null || current.minorUnits() < debit.minorUnits()) {
                throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Insufficient balance",
                        "The " + currency.getCurrencyCode() + " balance is " + (current == null ? "zero" : current) + "; cannot take " + debit + ".");
            }
            return current.minus(debit);
        });
        return new Debited(walletId, r.reference(), debit, balance);
    }

    private static Money amount(CreditRequest r) {
        Currency currency = supported(r.currency());
        Money money;
        try {
            money = Money.parse(r.amount(), currency);
        } catch (ArithmeticException tooPrecise) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Too many decimal places",
                    currency.getCurrencyCode() + " amounts have " + currency.getDefaultFractionDigits() + " decimal places; " + r.amount() + " has more.");
        }
        if (money.minorUnits() == 0) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Amount is zero", "The amount must be more than zero.");
        }
        return money;
    }

    private static Currency supported(String requested) {
        String code = requested.toUpperCase(Locale.ROOT);
        if (!SUPPORTED.contains(code)) {
            throw problem(HttpStatus.UNPROCESSABLE_CONTENT, "Currency not supported",
                    "This wallet holds " + String.join(", ", SUPPORTED.stream().sorted().toList()) + ", not " + code + ".");
        }
        return Currency.getInstance(code);
    }

    /** One balance per currency; with ?in=, also an indicative total converted at demo rates (challenge 2). */
    @GetMapping("/wallets/{id}/balance")
    Balances balance(@PathVariable String id, @RequestParam(required = false) String in) {
        String walletId = id.toLowerCase(Locale.ROOT);
        List<Money> balances = wallet(walletId).values().stream()
                .sorted(Comparator.comparing(m -> m.currency().getCurrencyCode())).toList();
        Money total = null;
        if (in != null) {
            Currency target = supported(in);
            total = balances.stream()
                    .map(m -> m.convertTo(target, DEMO_RATES_IN_INR.get(m.currency().getCurrencyCode()), DEMO_RATES_IN_INR.get(target.getCurrencyCode())))
                    .reduce(new Money(0, target), Money::plus);
        }
        return new Balances(walletId, balances, total);
    }

    private Map<Currency, Money> wallet(String id) {
        Map<Currency, Money> wallet = wallets.get(id);
        if (wallet == null) {
            throw problem(HttpStatus.NOT_FOUND, "Wallet not found", "No wallet has the id " + id + ".");
        }
        return wallet;
    }

    /** Empties every wallet. Used by the tests, so each starts from zero. */
    void clear() {
        wallets.values().forEach(Map::clear);
    }

    private static ErrorResponseException problem(HttpStatus status, String title, String detail) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(status, detail);
        p.setTitle(title);
        return new ErrorResponseException(status, p, null);
    }
}

Interview takeaways

Why are new BigDecimal("10.5") and new BigDecimal("10.50") not equal?

equals compares the unscaled value and the scale: 105 with scale 1 versus 1050 with scale 2. compareTo compares only the value, so it returns 0. HashMap and HashSet use equals and hashCode, so they keep both.

What makes a good value object?

Immutable, compared by its values, valid from construction, and with operations that return new values. A Java record gives the first two for free.

Why store minor units as a long?

Integers are exact, fast and compare simply. The currency says where the decimal point goes. A long holds more than any wallet needs; addExact turns an overflow into an error.

How do you stop rupees being added to dollars?

Make Money carry its currency and make plus refuse a different one. The mistake then fails loudly at the first test, not in a customer's balance.

Are all currencies two decimals?

No. ISO 4217 gives each currency's minor unit: JPY has none, some have three. java.util.Currency.getDefaultFractionDigits returns it.
