Level 1, about 5 minutes. Plain language: no code.

The problem in real life

  1. A tablet sends the wrong button

    A busy kitchen taps DELIVERED instead of ACCEPTED. The customer is told their food arrived; it has not been cooked.

  2. A cancelled order gets picked up

    The customer cancels; the rider's app still shows the order and marks it PICKED_UP. Food is made and carried for nobody.

  3. The fix

    Write the allowed moves down once, as a table. Every status change is checked against it, and a move it does not allow is refused with what is allowed instead.

A status is not a field anyone may set. It moves only along the arrows you drew.

What are we building?

POST /orders/{id}/status-changes moves an order to a new status if the table allows it from where it is now. GET /orders/{id} shows the order and its history.

An everyday analogy

A railway signal box: a train can only go from one block to the next one the signals allow. The signalman cannot send it from Pune straight to Delhi, and a cancelled train never leaves the platform.

How it works in 4 steps

  1. Find the order: no such order, 404.
  2. Same status again? A double tap: return the order unchanged.
  3. Check the table: not an allowed move, 409 naming what is allowed.
  4. Move: the check and the change are one step, and the change goes into the history.
Check yourself: the kitchen taps PREPARING and the customer taps cancel at the same moment. Both are allowed from ACCEPTED. What should happen?

Exactly one wins, and the other is told the order has moved on. If both "won", the kitchen would cook a cancelled order, or the customer would pay for food they cancelled.

What this station is not

  • No sign-in. Anyone may ask for any move here; challenge 1 adds who may do what.
  • No refunds or payments. Cancelling only changes the status.
  • No database. Three demo orders in memory.

Business problem

Tiffino (a fictional food delivery app) stores an order's status as whatever the last tablet or app sent. Kitchens mark orders DELIVERED before cooking them, riders pick up cancelled orders, and support cannot tell what really happened.

Acceptance criteria

  1. Given a placed order, then it can go ACCEPTED, PREPARING, READY_FOR_PICKUP, PICKED_UP, DELIVERED, one step at a time, with each step in its history.
  2. Given a placed order, when DELIVERED is asked, then 409 naming ACCEPTED, REJECTED and CANCELLED as allowed.
  3. Given a cancelled order, when any move is asked, then 409: nothing can change now.
  4. Given the current status asked again, then 200 and no new history entry.
  5. Given two allowed moves at the same instant, then exactly one happens.
  6. Given an unknown status or no status, then 400; an unknown order, 404.

Requirements

  • The table is the only rule: PLACED → ACCEPTED, REJECTED, CANCELLED; ACCEPTED → PREPARING, CANCELLED; PREPARING → READY_FOR_PICKUP; READY_FOR_PICKUP → PICKED_UP; PICKED_UP → DELIVERED.
  • DELIVERED, CANCELLED and REJECTED are final.
  • Status names are exact (ACCEPTED, not accepted).
  • Each move is checked and applied atomically; history times come from an injected clock.

Learning objectives

  • Model a lifecycle as an enum state machine with a transition table.
  • Use 409 for a valid request that conflicts with the current state.
  • Use Optional for "may not exist" instead of null.
  • Test a table exhaustively, and test two moves racing.

The trap

Plausible but wrong

Setting any status the client sends, so DELIVERED can come before PREPARING.

A setter is the simplest thing that works in a demo. The first test shows the old order accepting DELIVERED before anything else; the second, a cancelled order being picked up. The third shows the real flow refusing both with 409. While building, skipping the table check turned 3 tests red, treating a double tap as an error turned 1 red, and replacing the atomic move with get, check, put made the racing test fail in round 0 or 1 on each of 3 runs.

package com.tiffino.orders;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotNull;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

import java.util.Comparator;

@RestController
class OrderController {

    record StatusChange(@NotNull OrderStatus to) {
    }

    private final Orders orders;

    OrderController(Orders orders) {
        this.orders = orders;
    }

    @GetMapping("/orders/{id}")
    Orders.Order order(@PathVariable long id) {
        return orders.find(id).orElseThrow(() -> notFound(id));
    }

    /** 200 with the order after the move; 409 when the table does not allow it, naming what is allowed. */
    @PostMapping("/orders/{id}/status-changes")
    Orders.Order change(@PathVariable long id, @Valid @RequestBody StatusChange change) {
        try {
            return orders.move(id, change.to()).orElseThrow(() -> notFound(id));
        } catch (Orders.IllegalMove e) {
            String allowed = e.from.next().stream().sorted(Comparator.naturalOrder()).map(Enum::name).toList().toString();
            ProblemDetail p = ProblemDetail.forStatusAndDetail(HttpStatus.CONFLICT,
                    e.getMessage() + (e.from.isTerminal() ? " It is " + e.from + ": nothing can change now." : " Allowed next: " + allowed + "."));
            p.setTitle("Status change not allowed");
            p.setProperty("currentStatus", e.from);
            p.setProperty("allowedNext", e.from.next());
            throw new ErrorResponseException(HttpStatus.CONFLICT, p, e);
        }
    }

    private static ErrorResponseException notFound(long id) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, "No order " + id + ".");
        p.setTitle("Order not found");
        return new ErrorResponseException(HttpStatus.NOT_FOUND, p, null);
    }
}

src/main/java/com/tiffino/orders/OrderStatus.java

Does
The statuses and the transition table.
Why
One EnumMap is the whole rule: easy to read, easy to test exhaustively.
Without it
The trap: no table at all.
  • The table is filled in a static block, because an enum constant cannot refer to constants declared after it.
  • Terminal statuses map to empty sets.
package com.tiffino.orders;

import java.util.EnumMap;
import java.util.EnumSet;
import java.util.Map;
import java.util.Set;

/**
 * An order's life as a state machine. The transition table is the whole rule: a move not in it is refused,
 * whoever asks. Terminal statuses (DELIVERED, CANCELLED, REJECTED) have no way out.
 */
enum OrderStatus {
    PLACED, ACCEPTED, REJECTED, PREPARING, READY_FOR_PICKUP, PICKED_UP, DELIVERED, CANCELLED;

    private static final Map<OrderStatus, Set<OrderStatus>> NEXT = new EnumMap<>(OrderStatus.class);

    static {
        NEXT.put(PLACED, EnumSet.of(ACCEPTED, REJECTED, CANCELLED));
        NEXT.put(ACCEPTED, EnumSet.of(PREPARING, CANCELLED));
        NEXT.put(PREPARING, EnumSet.of(READY_FOR_PICKUP));
        NEXT.put(READY_FOR_PICKUP, EnumSet.of(PICKED_UP));
        NEXT.put(PICKED_UP, EnumSet.of(DELIVERED));
        NEXT.put(DELIVERED, EnumSet.noneOf(OrderStatus.class));
        NEXT.put(CANCELLED, EnumSet.noneOf(OrderStatus.class));
        NEXT.put(REJECTED, EnumSet.noneOf(OrderStatus.class));
    }

    Set<OrderStatus> next() {
        return NEXT.get(this);
    }

    boolean canMoveTo(OrderStatus to) {
        return NEXT.get(this).contains(to);
    }

    boolean isTerminal() {
        return NEXT.get(this).isEmpty();
    }
}

The orders, and the only method that changes a status.
Why
computeIfPresent: check the table and write the new status as one step per order.

package com.tiffino.orders;

import org.springframework.stereotype.Component;

import java.time.Clock;
import java.time.Instant;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;

/**
 * Orders in memory (demo data), and the one place a status changes. Each change is a single compute() on the order:
 * check the table and write the new status as one step, so two tablets tapping at once cannot both win.
 */
@Component
class Orders {

    record Change(OrderStatus status, Instant at) {
    }

    record Order(long id, String restaurant, OrderStatus status, List<Change> history) {
    }

    /** A move the table does not allow, with what is allowed instead. */
    static final class IllegalMove extends RuntimeException {
        final OrderStatus from;
        final OrderStatus to;

        IllegalMove(long id, OrderStatus from, OrderStatus to) {
            super("Order " + id + " cannot go from " + from + " to " + to + ".");
            this.from = from;
            this.to = to;
        }
    }

    private final Clock clock;
    private final Map<Long, Order> byId = new ConcurrentHashMap<>();

    Orders(Clock clock) {
        this.clock = clock;
        reset();
    }

    Optional<Order> find(long id) {
        return Optional.ofNullable(byId.get(id));
    }

    /**
     * Moves the order, or throws IllegalMove. Asking for the status it already has is not a move: the order comes
     * back unchanged (a tablet double tap, or a retry after a timeout).
     */
    Optional<Order> move(long id, OrderStatus to) {
        return Optional.ofNullable(byId.computeIfPresent(id, (key, order) -> {
            if (order.status() == to) {
                return order;
            }
            if (!order.status().canMoveTo(to)) {
                throw new IllegalMove(id, order.status(), to);
            }
            List<Change> history = new java.util.ArrayList<>(order.history());
            history.add(new Change(to, clock.instant().truncatedTo(java.time.temporal.ChronoUnit.SECONDS)));
            return new Order(id, order.restaurant(), to, List.copyOf(history));
        }));
    }

    /** Demo orders: one just placed, one cancelled, one being prepared. Also used by tests to start clean. */
    void reset() {
        byId.clear();
        Instant now = clock.instant().truncatedTo(java.time.temporal.ChronoUnit.SECONDS);
        byId.put(1001L, new Order(1001, "Annapoorna Mess", OrderStatus.PLACED, List.of(new Change(OrderStatus.PLACED, now))));
        byId.put(1002L, new Order(1002, "Annapoorna Mess", OrderStatus.CANCELLED,
                List.of(new Change(OrderStatus.PLACED, now), new Change(OrderStatus.CANCELLED, now))));
        byId.put(1003L, new Order(1003, "Biryani Point", OrderStatus.PREPARING, List.of(new Change(OrderStatus.PLACED, now),
                new Change(OrderStatus.ACCEPTED, now), new Change(OrderStatus.PREPARING, now))));
    }
}

src/test/java/com/tiffino/orders/TransitionTableTest.java

All 64 pairs against a rule written by hand, reachability, and two moves racing for 50 rounds.

package com.tiffino.orders;

import org.junit.jupiter.api.Test;

import java.time.Clock;
import java.util.ArrayDeque;
import java.util.EnumSet;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.Executors;

import static com.tiffino.orders.OrderStatus.*;
import static org.assertj.core.api.Assertions.assertThat;

/** The table itself: every pair checked against the rule written out by hand, and two moves racing. */
class TransitionTableTest {

    /** The business rule, written independently of the code. */
    static final Map<OrderStatus, Set<OrderStatus>> EXPECTED = Map.of(
            PLACED, EnumSet.of(ACCEPTED, REJECTED, CANCELLED),
            ACCEPTED, EnumSet.of(PREPARING, CANCELLED),
            PREPARING, EnumSet.of(READY_FOR_PICKUP),
            READY_FOR_PICKUP, EnumSet.of(PICKED_UP),
            PICKED_UP, EnumSet.of(DELIVERED),
            DELIVERED, EnumSet.noneOf(OrderStatus.class),
            CANCELLED, EnumSet.noneOf(OrderStatus.class),
            REJECTED, EnumSet.noneOf(OrderStatus.class));

    @Test
    void everyPairOfStatusesMatchesTheRule() {
        for (OrderStatus from : OrderStatus.values()) {
            for (OrderStatus to : OrderStatus.values()) {
                assertThat(from.canMoveTo(to)).as(from + " -> " + to).isEqualTo(EXPECTED.get(from).contains(to));
            }
        }
    }

    @Test
    void everyStatusIsReachableFromPlacedAndOnlyEndsHaveNoWayOut() {
        Set<OrderStatus> seen = EnumSet.of(PLACED);
        ArrayDeque<OrderStatus> todo = new ArrayDeque<>(List.of(PLACED));
        while (!todo.isEmpty()) {
            for (OrderStatus next : todo.poll().next()) {
                if (seen.add(next)) {
                    todo.add(next);
                }
            }
        }
        assertThat(seen).containsExactlyInAnyOrder(OrderStatus.values());
        assertThat(EnumSet.allOf(OrderStatus.class).stream().filter(OrderStatus::isTerminal)).containsExactlyInAnyOrder(DELIVERED, CANCELLED, REJECTED);
    }

    @Test
    void whenTheKitchenAndTheCustomerTapAtOnceExactlyOneWins() throws Exception {
        for (int round = 0; round < 50; round++) {
            Orders orders = new Orders(Clock.systemUTC());
            orders.move(1001, ACCEPTED);
            Map<OrderStatus, Boolean> won = new ConcurrentHashMap<>();
            CountDownLatch start = new CountDownLatch(1);
            try (var threads = Executors.newVirtualThreadPerTaskExecutor()) {
                for (OrderStatus to : List.of(PREPARING, CANCELLED)) {
                    threads.submit(() -> {
                        start.await();
                        try {
                            orders.move(1001, to);
                            won.put(to, true);
                        } catch (Orders.IllegalMove lost) {
                            won.put(to, false);
                        }
                        return null;
                    });
                }
                start.countDown();
            }
            assertThat(won.values()).as("round " + round).containsExactlyInAnyOrder(true, false);
            OrderStatus winner = won.get(PREPARING) ? PREPARING : CANCELLED;
            assertThat(orders.find(1001).orElseThrow().status()).isEqualTo(winner);
            assertThat(orders.find(1001).orElseThrow().history()).hasSize(3);
        }
    }
}

package com.tiffino.orders;

import java.util.EnumSet;
import java.util.Set;

/** Challenge 1: who may move an order to which status. An enum with data: each party carries its own moves. */
enum Actor {
    RESTAURANT(EnumSet.of(OrderStatus.ACCEPTED, OrderStatus.REJECTED, OrderStatus.PREPARING, OrderStatus.READY_FOR_PICKUP, OrderStatus.CANCELLED)),
    RIDER(EnumSet.of(OrderStatus.PICKED_UP, OrderStatus.DELIVERED)),
    CUSTOMER(EnumSet.of(OrderStatus.CANCELLED));

    private final Set<OrderStatus> mayMoveTo;

    Actor(Set<OrderStatus> mayMoveTo) {
        this.mayMoveTo = mayMoveTo;
    }

    boolean mayMoveTo(OrderStatus to) {
        return mayMoveTo.contains(to);
    }
}

challenge/solution/OrderController.java

package com.tiffino.orders;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotNull;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.web.ErrorResponseException;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RestController;

import java.util.Comparator;

@RestController
class OrderController {

    record StatusChange(@NotNull OrderStatus to) {
    }

    private final Orders orders;

    OrderController(Orders orders) {
        this.orders = orders;
    }

    @GetMapping("/orders/{id}")
    Orders.Order order(@PathVariable long id) {
        return orders.find(id).orElseThrow(() -> notFound(id));
    }

    /** 200 with the order after the move; 409 when the table does not allow it, naming what is allowed. */
    @PostMapping("/orders/{id}/status-changes")
    Orders.Order change(@PathVariable long id, @RequestHeader("X-Actor") Actor actor, @Valid @RequestBody StatusChange change) {
        // Challenge 1: X-Actor stands in for real sign-in in this demo; a real app takes the party from the login.
        if (!actor.mayMoveTo(change.to())) {
            ProblemDetail p = ProblemDetail.forStatusAndDetail(HttpStatus.FORBIDDEN, actor + " may not move an order to " + change.to() + ".");
            p.setTitle("Not your move");
            throw new ErrorResponseException(HttpStatus.FORBIDDEN, p, null);
        }
        try {
            return orders.move(id, change.to()).orElseThrow(() -> notFound(id));
        } catch (Orders.IllegalMove e) {
            String allowed = e.from.next().stream().sorted(Comparator.naturalOrder()).map(Enum::name).toList().toString();
            ProblemDetail p = ProblemDetail.forStatusAndDetail(HttpStatus.CONFLICT,
                    e.getMessage() + (e.from.isTerminal() ? " It is " + e.from + ": nothing can change now." : " Allowed next: " + allowed + "."));
            p.setTitle("Status change not allowed");
            p.setProperty("currentStatus", e.from);
            p.setProperty("allowedNext", e.from.next());
            throw new ErrorResponseException(HttpStatus.CONFLICT, p, e);
        }
    }

    private static ErrorResponseException notFound(long id) {
        ProblemDetail p = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, "No order " + id + ".");
        p.setTitle("Order not found");
        return new ErrorResponseException(HttpStatus.NOT_FOUND, p, null);
    }
}

package com.tiffino.orders;

import org.springframework.stereotype.Component;

import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;

/**
 * Orders in memory (demo data), and the one place a status changes. Each change is a single compute() on the order:
 * check the table and write the new status as one step, so two tablets tapping at once cannot both win.
 */
@Component
class Orders {

    record Change(OrderStatus status, Instant at) {
    }

    record Order(long id, String restaurant, OrderStatus status, List<Change> history) {
    }

    /** A move the table does not allow, with what is allowed instead. */
    static final class IllegalMove extends RuntimeException {
        final OrderStatus from;
        final OrderStatus to;

        IllegalMove(long id, OrderStatus from, OrderStatus to) {
            super("Order " + id + " cannot go from " + from + " to " + to + ".");
            this.from = from;
            this.to = to;
        }
    }

    /** Challenge 2: how long a kitchen may take back a READY_FOR_PICKUP tapped by mistake. */
    static final Duration UNDO_READY_WITHIN = Duration.ofMinutes(2);

    private final Clock clock;
    private final Map<Long, Order> byId = new ConcurrentHashMap<>();

    Orders(Clock clock) {
        this.clock = clock;
        reset();
    }

    Optional<Order> find(long id) {
        return Optional.ofNullable(byId.get(id));
    }

    /**
     * Moves the order, or throws IllegalMove. Asking for the status it already has is not a move: the order comes
     * back unchanged (a tablet double tap, or a retry after a timeout).
     */
    Optional<Order> move(long id, OrderStatus to) {
        return Optional.ofNullable(byId.computeIfPresent(id, (key, order) -> {
            if (order.status() == to) {
                return order;
            }
            if (!order.status().canMoveTo(to) && !undoesARecentReady(order, to)) {
                throw new IllegalMove(id, order.status(), to);
            }
            List<Change> history = new java.util.ArrayList<>(order.history());
            history.add(new Change(to, clock.instant().truncatedTo(java.time.temporal.ChronoUnit.SECONDS)));
            return new Order(id, order.restaurant(), to, List.copyOf(history));
        }));
    }

    /** Challenge 2: READY_FOR_PICKUP back to PREPARING, only within the undo window. */
    private boolean undoesARecentReady(Order order, OrderStatus to) {
        Change last = order.history().getLast();
        return order.status() == OrderStatus.READY_FOR_PICKUP && to == OrderStatus.PREPARING
                && last.at().plus(UNDO_READY_WITHIN).isAfter(clock.instant());
    }

    /** Demo orders: one just placed, one cancelled, one being prepared. Also used by tests to start clean. */
    void reset() {
        byId.clear();
        Instant now = clock.instant().truncatedTo(java.time.temporal.ChronoUnit.SECONDS);
        byId.put(1001L, new Order(1001, "Annapoorna Mess", OrderStatus.PLACED, List.of(new Change(OrderStatus.PLACED, now))));
        byId.put(1002L, new Order(1002, "Annapoorna Mess", OrderStatus.CANCELLED,
                List.of(new Change(OrderStatus.PLACED, now), new Change(OrderStatus.CANCELLED, now))));
        byId.put(1003L, new Order(1003, "Biryani Point", OrderStatus.PREPARING, List.of(new Change(OrderStatus.PLACED, now),
                new Change(OrderStatus.ACCEPTED, now), new Change(OrderStatus.PREPARING, now))));
    }
}

Interview takeaways

Why model order status as a state machine?

Because only some moves make sense. A table of allowed moves turns every impossible order (delivered before cooked) into a refused request instead of bad data.

Which status code for an illegal move?

409 Conflict: the request is well formed, but it conflicts with the order's current state. 400 is for a malformed request.

How do you stop two moves at once from both happening?

Make the check and the write one atomic step: compute on a ConcurrentHashMap in memory, or UPDATE … WHERE status = expected in a database.

Why return 200 for the same status twice?

Clients retry and double tap. The order is already in that state, so the request has its intended effect; an error would only confuse the app.

What is Optional for?

To say in the type that a value may be missing, and make the caller decide what to do (orElseThrow, map) instead of meeting a null later.
