The problem in real life

  1. Down for five minutes

    Ravi's shop server restarts for an update. In those five minutes three customers pay. Paysetu posts each "payment captured" once, gets a 503, and moves on.

  2. Orders that never ship

    Ravi's system never hears about the three payments, so the orders stay unpaid. The customers call; Ravi calls Paysetu. And because nothing was signed, a fake "paid" sent by anyone would have shipped goods for free.

  3. The fix

    Each payment is written with a delivery for each of Ravi's servers, in one transaction. A dispatcher sends them signed, waits longer after each failure, logs every try, and after eight failures keeps the delivery as failed for a person to see.

A notification you send once is a notification you lose. Write it down first, sign it, retry it, and keep the record.

What are we building?

Merchants register a URL and get a secret. Every captured payment is delivered to each URL, signed, retried with growing waits, and listed in a delivery log the merchant can read.

An everyday analogy

A courier service: each parcel is booked before it leaves, sealed, tried again tomorrow and the day after when nobody is home, and after the last try it waits at the depot. The tracking page shows every doorstep visit.

How it works in 4 steps

  1. Register: the merchant gives a URL and gets a signing secret, shown once.
  2. Record: a captured payment writes an event and one delivery per URL in one transaction.
  3. Send: every second a dispatcher takes what is due, signs it and posts it. 2xx means delivered.
  4. Retry or stop: after a failure it waits 30 s, then twice as long each time; the 8th failure is final.
Check yourself: the merchant's server took the request, saved the payment, then crashed before answering. What happens?

We see no 2xx, so we retry, and the merchant gets the same payment twice. That is why every retry carries the same webhook-id: the merchant drops repeats by it. Webhooks are delivered at least once, not exactly once.

What this station is not

  • No real payments. A test event stands in for a captured payment.
  • No checks of where a URL points. A merchant could register an internal address; see Production.
  • No ordering. A retry can arrive after a newer event.

Business problem

Paysetu (a fictional payments company): merchants miss payment notifications when their server is down for five minutes, and cannot tell a real notification from a forged one.

Acceptance criteria

Demo users: ravi (merchant 1) and meena (merchant 2); password: the name plus -demo-pass. Demo rules: first retry after 30 s, doubled each time, 8 attempts (about an hour); 5 s per attempt; signatures older than 5 minutes refused.

  1. Given a valid URL, then 201 with a whsec_ secret, shown only here; the same URL again 409.
  2. Given a captured payment, then 202 and, within a second, a POST to each URL with webhook-id, webhook-timestamp and a valid webhook-signature.
  3. Given the merchant down for five minutes, then the payment arrives on the first try after it is back (7.5 minutes in), with the same id.
  4. Given eight failures, then the delivery is FAILED and not tried again; the log shows all eight.
  5. Given the same payment reported twice, then one event and one delivery per URL; with another amount 409.
  6. Given another merchant's id or delivery, then 403 or 404; no sign-in 401.

Requirements

  • Nothing is sent inside the request that records the payment.
  • Two servers running the dispatcher never send the same delivery at the same time.
  • The attempt limit, the states and the one-delivery-per-endpoint rule are also database constraints.

Learning objectives

  • Write an event and its deliveries atomically (a transactional outbox) and send them from a @Scheduled job.
  • Sign requests with HMAC-SHA256 and verify them in constant time with a timestamp tolerance.
  • Retry with exponential backoff and stop with a dead letter.
  • Claim work from a table safely with FOR UPDATE SKIP LOCKED and a lease.
  • Test time-based behaviour with a clock you move, not with sleeps.

The trap

Plausible but wrong

Fire-and-forget delivery with no signature, retry or delivery log.

  • The old way. The test posts the payment once with sendAsync and never reads the answer. The merchant answers 503; ten minutes later it is back, and nothing comes: there is no record to retry from. The request had no signature, so a forged one would look the same.
  • The API. The merchant is down for the first five minutes. Tries at 0 s, 30 s, 90 s, 210 s and 450 s; the fifth is answered 200. Every try is signed afresh and carries the same id.

While building, each part was undone once: a fixed 30 s wait turned 2 tests red; no attempt limit 1; no signature header 3; a new id on each try 2; following redirects 1; no per-attempt timeout 1; no timestamp check 1; no transaction around the event and its deliveries 1; any merchant's id 1; every merchant's deliveries listed 1; no amount check on repeats 1; user names allowed in URLs 1; payment refs not upper-cased 2. Removing SKIP LOCKED at first turned nothing red (see Tests); a test that holds a lock now catches it.

package com.paysetu.webhooks;

import org.junit.jupiter.api.Test;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.concurrent.CompletableFuture;

import static org.assertj.core.api.Assertions.assertThat;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

/** The merchant's server is down for five minutes. Written first. */
class FireAndForgetTrapTest extends ApiTest {

    /** The old way: post it right after the payment and never look at the answer. No signature, no retry, no log. */
    static CompletableFuture<HttpResponse<Void>> oldWay(String url, String body) {
        return HttpClient.newHttpClient().sendAsync(HttpRequest.newBuilder(URI.create(url)).header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString(body)).build(), HttpResponse.BodyHandlers.discarding());
    }

    @Test
    void theOldWayLosesThePaymentWhileTheMerchantIsDown() throws Exception {
        try (TestMerchant merchant = new TestMerchant(CLOCK)) {
            merchant.answer = () -> 503;   // down for maintenance
            oldWay(merchant.url(), "{\"type\":\"payment.captured\",\"data\":{\"paymentRef\":\"PAY-1001\",\"amountPaise\":49900}}").join();
            merchant.answer = () -> 200;   // back after five minutes
            CLOCK.advance(Duration.ofMinutes(10));
            dispatcher.dispatchDue();

            assertThat(merchant.received()).hasSize(1);   // the one try, answered 503, and never again
            assertThat(merchant.received().getFirst().signature()).isNull();   // and anyone could have sent it
            assertThat(jdbc.sql("SELECT count(*) FROM deliveries").query(Long.class).single()).isZero();   // nothing to retry from
        }
    }

    @Test
    void theApiKeepsThePaymentUntilTheMerchantIsBack() throws Exception {
        try (TestMerchant merchant = new TestMerchant(CLOCK)) {
            merchant.answer = () -> CLOCK.instant().isBefore(T0.plus(Duration.ofMinutes(5))) ? 503 : 200;
            String secret = secretFor("ravi", 1, merchant.url());
            testEvent("ravi", 1, "PAY-1001", 49900).andExpect(status().isAccepted());

            for (int second = 0; second <= 600; second += 10) {   // ten minutes, a dispatcher round every 10 s
                CLOCK.set(T0.plusSeconds(second));
                dispatcher.dispatchDue();
            }

            // Tried at once, then after 30 s, 1 min, 2 min and 4 min: the fifth try, 7.5 minutes in, is answered 200.
            assertThat(merchant.received()).extracting(r -> Duration.between(T0, r.at()).toSeconds()).containsExactly(0L, 30L, 90L, 210L, 450L);
            assertThat(merchant.received()).allMatch(r -> r.verifiedWith(secret));   // each try signed afresh
            assertThat(merchant.received()).extracting(TestMerchant.Received::id).containsOnly(merchant.received().getFirst().id());   // one id: the merchant can drop repeats
            var log = onlyDelivery("ravi");
            assertThat(log.at("/delivery/status").asString()).isEqualTo("DELIVERED");
            assertThat(log.at("/delivery/deliveredAt").asString()).isEqualTo("2026-10-23T10:07:30Z");
            assertThat(log.get("attempts")).extracting(a -> a.get("statusCode").asInt()).containsExactly(503, 503, 503, 503, 200);
        }
    }
}

package com.paysetu.webhooks;

import org.springframework.dao.DuplicateKeyException;
import org.springframework.http.HttpStatus;
import org.springframework.http.ProblemDetail;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.ErrorResponseException;
import tools.jackson.databind.json.JsonMapper;

import java.net.URI;
import java.net.URISyntaxException;
import java.time.Clock;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.time.temporal.ChronoUnit;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Optional;
import java.util.UUID;

/** Endpoints, events and the delivery log. Sending is the Dispatcher's job, never done inside a request. */
@Service
class Webhooks {

    enum Status { PENDING, DELIVERED, FAILED }

    record Endpoint(long id, String url, String secret, OffsetDateTime createdAt) {
    }

    record Recorded(UUID eventId, String paymentRef, int deliveries, boolean replay) {
    }

    record Delivery(long id, UUID eventId, String type, String paymentRef, String endpointUrl, Status status, int attempts,
                    Integer lastStatusCode, String lastError, OffsetDateTime nextAttemptAt, OffsetDateTime deliveredAt) {
    }

    record Attempt(OffsetDateTime attemptedAt, Integer statusCode, String error, int durationMs) {
    }

    record DeliveryLog(Delivery delivery, List<Attempt> attempts) {
    }

    private static final JsonMapper JSON = JsonMapper.builder().build();
    private final JdbcClient jdbc;
    private final Clock clock;

    Webhooks(JdbcClient jdbc, Clock clock) {
        this.jdbc = jdbc;
        this.clock = clock;
    }

    Endpoint register(long merchantId, String url) {
        String checked = checkedUrl(url);
        String secret = WebhookSignature.newSecret();
        try {
            return jdbc.sql("""
                            INSERT INTO webhook_endpoints (merchant_id, url, secret, created_at) VALUES (?, ?, ?, ?)
                            RETURNING id, url, secret, created_at""")
                    .params(merchantId, checked, secret, now()).query(Endpoint.class).single();
        } catch (DuplicateKeyException e) {
            throw problem(HttpStatus.CONFLICT, "This URL is already registered for this merchant.");
        }
    }

    /**
     * shortcut: no check of where the URL points (a private address, the cloud metadata service). Before letting
     * merchants register URLs in production, add the address checks of an SSRF-safe fetcher.
     */
    static String checkedUrl(String url) {
        URI uri;
        try {
            uri = new URI(url);
        } catch (URISyntaxException e) {
            throw problem(HttpStatus.BAD_REQUEST, "The URL is not a valid URL.");
        }
        String scheme = uri.getScheme() == null ? "" : uri.getScheme().toLowerCase(Locale.ROOT);
        if (!scheme.equals("https") && !scheme.equals("http") || uri.getHost() == null || uri.getRawUserInfo() != null || uri.getRawFragment() != null) {
            throw problem(HttpStatus.BAD_REQUEST, "The URL must be http or https, with a host and without a user name or #fragment.");
        }
        return uri.toString();
    }

    /**
     * Records that a payment was captured, and one delivery per endpoint, in one transaction (the outbox): either
     * both exist or neither. Reporting the same payment again changes nothing and returns the first event.
     */
    @Transactional
    Recorded paymentCaptured(long merchantId, String paymentRef, long amountPaise) {
        String ref = paymentRef.strip().toUpperCase(Locale.ROOT);
        OffsetDateTime now = now();
        Map<String, Object> data = new LinkedHashMap<>();
        data.put("paymentRef", ref);
        data.put("amountPaise", amountPaise);
        Map<String, Object> payload = new LinkedHashMap<>();
        payload.put("type", "payment.captured");
        payload.put("timestamp", now.toInstant().toString());
        payload.put("data", data);
        Optional<UUID> inserted = jdbc.sql("""
                        INSERT INTO events (id, merchant_id, type, object_ref, amount_paise, payload, created_at)
                        VALUES (?, ?, 'payment.captured', ?, ?, ?, ?)
                        ON CONFLICT ON CONSTRAINT events_once_per_object DO NOTHING RETURNING id""")
                .params(UUID.randomUUID(), merchantId, ref, amountPaise, JSON.writeValueAsString(payload), now).query(UUID.class).optional();
        if (inserted.isPresent()) {
            int deliveries = jdbc.sql("INSERT INTO deliveries (event_id, endpoint_id, next_attempt_at) SELECT ?, id, ? FROM webhook_endpoints WHERE merchant_id = ? ORDER BY id")
                    .params(inserted.get(), now, merchantId).update();
            return new Recorded(inserted.get(), ref, deliveries, false);
        }
        record Existing(UUID id, long amountPaise, int deliveries) {
        }
        Existing first = jdbc.sql("""
                        SELECT e.id, e.amount_paise, (SELECT count(*) FROM deliveries d WHERE d.event_id = e.id) AS deliveries
                        FROM events e WHERE merchant_id = ? AND type = 'payment.captured' AND object_ref = ?""")
                .params(merchantId, ref).query(Existing.class).single();
        if (first.amountPaise() != amountPaise) {
            throw problem(HttpStatus.CONFLICT, ref + " was already reported with a different amount.");
        }
        return new Recorded(first.id(), ref, first.deliveries(), true);
    }

    private static final String DELIVERY = """
            SELECT d.id, d.event_id, e.type, e.object_ref AS payment_ref, w.url AS endpoint_url, d.status, d.attempts,
                   d.last_status_code, d.last_error, d.next_attempt_at, d.delivered_at
            FROM deliveries d JOIN events e ON e.id = d.event_id JOIN webhook_endpoints w ON w.id = d.endpoint_id
            WHERE w.merchant_id = :merchant""";

    /** shortcut: the newest 100, no paging; add a cursor (?after=id) when merchants have more. */
    List<Delivery> deliveries(long merchantId, Status status) {
        return jdbc.sql(DELIVERY + " AND (CAST(:status AS text) IS NULL OR d.status = :status) ORDER BY d.id DESC LIMIT 100")
                .param("merchant", merchantId).param("status", status == null ? null : status.name()).query(Delivery.class).list();
    }

    Optional<DeliveryLog> delivery(long merchantId, long id) {
        return jdbc.sql(DELIVERY + " AND d.id = :id").param("merchant", merchantId).param("id", id).query(Delivery.class).optional()
                .map(d -> new DeliveryLog(d, jdbc.sql("SELECT attempted_at, status_code, error, duration_ms FROM delivery_attempts WHERE delivery_id = ? ORDER BY id")
                        .param(id).query(Attempt.class).list()));
    }

    static ErrorResponseException problem(HttpStatus status, String detail) {
        return new ErrorResponseException(status, ProblemDetail.forStatusAndDetail(status, detail), null);
    }

    private OffsetDateTime now() {
        return OffsetDateTime.now(clock).withOffsetSameInstant(ZoneOffset.UTC).truncatedTo(ChronoUnit.MICROS);
    }
}

src/main/java/com/paysetu/webhooks/Dispatcher.java

Does
Sending, retrying, giving up.
Why
Claims due deliveries in one statement, sends each on a virtual thread, records the attempt and the next one.
Without it
A payment lost to a five-minute outage, or sent twice by two servers.
  • The claim moves the next attempt past a lease (timeout + 30 s), so other rounds do not see it while we send. If this server dies mid-send, the lease runs out and another server tries again: at least once.
  • The update checks attempts is still what we claimed; if another round got there first, ours is rolled back.
  • Redirects are not followed: the merchant registered this URL.
package com.paysetu.webhooks;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Component;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.support.TransactionTemplate;

import java.io.IOException;
import java.net.ConnectException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.net.http.HttpTimeoutException;
import java.time.Clock;
import java.time.Duration;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.time.temporal.ChronoUnit;
import java.util.List;
import java.util.UUID;
import java.util.concurrent.Executors;

/**
 * Works through the outbox: claims the deliveries that are due, sends each one signed, and records every attempt.
 * Several servers may run it at once: a claimed delivery is invisible to the others until its lease ends.
 */
@Component
class Dispatcher {

    static final int MAX_ATTEMPTS = 8;   // also the deliveries_attempts_range constraint
    static final int BATCH = 20;
    private static final Logger log = LoggerFactory.getLogger(Dispatcher.class);

    private final JdbcClient jdbc;
    private final Clock clock;
    private final TransactionTemplate tx;
    private final Duration firstRetry;
    private final Duration timeout;
    private final HttpClient http;

    Dispatcher(JdbcClient jdbc, Clock clock, PlatformTransactionManager transactions,
               @Value("${paysetu.webhooks.first-retry}") Duration firstRetry, @Value("${paysetu.webhooks.timeout}") Duration timeout) {
        this.jdbc = jdbc;
        this.clock = clock;
        this.tx = new TransactionTemplate(transactions);
        this.firstRetry = firstRetry;
        this.timeout = timeout;
        // Redirects are not followed: the merchant registered this URL, not wherever it points us next.
        this.http = HttpClient.newBuilder().connectTimeout(timeout).followRedirects(HttpClient.Redirect.NEVER).build();
    }

    record Due(long id, int attempts, UUID eventId, String payload, String url, String secret) {
    }

    /** One round. Returns how many deliveries it tried. */
    int dispatchDue() {
        List<Due> due = claim(now());
        try (var threads = Executors.newVirtualThreadPerTaskExecutor()) {   // one slow merchant does not hold up the rest
            for (Due d : due) {
                threads.execute(() -> {
                    try {
                        attempt(d);
                    } catch (RuntimeException e) {
                        log.warn("Delivery {} could not be recorded; it is tried again when its lease ends", d.id(), e);
                    }
                });
            }
        }
        return due.size();
    }

    /**
     * One statement: the due rows are locked (rows another server has locked are skipped) and their next attempt
     * moved past the lease, so no other round picks them up while we send.
     */
    private List<Due> claim(OffsetDateTime now) {
        return jdbc.sql("""
                        UPDATE deliveries d SET next_attempt_at = :leaseEnd
                        FROM events e, webhook_endpoints w
                        WHERE d.id IN (SELECT id FROM deliveries
                                       WHERE status = 'PENDING' AND next_attempt_at <= :now
                                       ORDER BY next_attempt_at, id LIMIT :batch
                                       FOR UPDATE SKIP LOCKED)
                          AND e.id = d.event_id AND w.id = d.endpoint_id
                        RETURNING d.id, d.attempts, e.id AS event_id, e.payload, w.url, w.secret""")
                .param("now", now).param("leaseEnd", now.plus(timeout).plusSeconds(30)).param("batch", BATCH)
                .query(Due.class).list();
    }

    private void attempt(Due d) {
        OffsetDateTime at = now();
        String id = d.eventId().toString();
        long timestamp = at.toEpochSecond();
        HttpRequest request = HttpRequest.newBuilder(URI.create(d.url())).timeout(timeout)
                .header("Content-Type", "application/json")
                .header("User-Agent", "Paysetu-Webhooks/1.0")
                .header("webhook-id", id)   // the same on every retry: the merchant drops repeats by it
                .header("webhook-timestamp", Long.toString(timestamp))
                .header("webhook-signature", WebhookSignature.sign(d.secret(), id, timestamp, d.payload()))
                .POST(HttpRequest.BodyPublishers.ofString(d.payload())).build();
        long started = System.nanoTime();
        Integer code = null;
        String error = null;
        try {
            code = http.send(request, HttpResponse.BodyHandlers.discarding()).statusCode();
            if (code / 100 != 2) {
                error = "HTTP " + code + (code / 100 == 3 ? " (redirects are not followed)" : "");
            }
        } catch (HttpTimeoutException e) {
            error = "timed out after " + timeout.toMillis() + " ms";
        } catch (ConnectException e) {
            error = "could not connect";
        } catch (IOException e) {
            error = e.getClass().getSimpleName();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return;   // nothing recorded: tried again when the lease ends
        }
        record(d, at, code, error, (int) ((System.nanoTime() - started) / 1_000_000));
    }

    private void record(Due d, OffsetDateTime at, Integer code, String error, int durationMs) {
        int attempts = d.attempts() + 1;
        String status = error == null ? "DELIVERED" : attempts >= MAX_ATTEMPTS ? "FAILED" : "PENDING";
        OffsetDateTime next = status.equals("PENDING") ? at.plus(backoff(firstRetry, attempts)) : null;
        tx.executeWithoutResult(s -> {
            jdbc.sql("INSERT INTO delivery_attempts (delivery_id, attempted_at, status_code, error, duration_ms) VALUES (?, ?, ?, ?, ?)")
                    .params(d.id(), at, code, error, durationMs).update();
            int updated = jdbc.sql("""
                            UPDATE deliveries SET status = ?, attempts = ?, next_attempt_at = ?, last_status_code = ?, last_error = ?, delivered_at = ?
                            WHERE id = ? AND attempts = ?""")
                    .params(status, attempts, next, code, error, status.equals("DELIVERED") ? at : null, d.id(), d.attempts()).update();
            if (updated != 1) {   // the lease ran out and another round recorded this attempt: keep theirs
                throw new IllegalStateException("delivery " + d.id() + " was recorded by another round");
            }
        });
    }

    /** After the n-th failure: first-retry, then twice as long each time (30 s, 1 min, 2 min, ... 32 min). */
    static Duration backoff(Duration firstRetry, int failedAttempts) {
        return firstRetry.multipliedBy(1L << (failedAttempts - 1));
    }

    private OffsetDateTime now() {
        return OffsetDateTime.now(clock).withOffsetSameInstant(ZoneOffset.UTC).truncatedTo(ChronoUnit.MICROS);
    }
}

package com.paysetu.webhooks;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.security.GeneralSecurityException;
import java.security.MessageDigest;
import java.security.SecureRandom;
import java.time.Duration;
import java.time.Instant;
import java.util.Base64;

/**
 * Signatures in the Standard Webhooks format (standardwebhooks.com, a community specification, not an IETF or W3C
 * standard): HMAC-SHA256 over "id.timestamp.body", sent as "v1,base64". {@link #verify} is what a merchant runs.
 */
final class WebhookSignature {

    /** A request older or newer than this is refused, so a recorded request cannot be replayed later. */
    static final Duration TOLERANCE = Duration.ofMinutes(5);
    private static final SecureRandom RANDOM = new SecureRandom();

    private WebhookSignature() {
    }

    static String newSecret() {
        byte[] key = new byte[24];
        RANDOM.nextBytes(key);
        return "whsec_" + Base64.getEncoder().encodeToString(key);
    }

    static String sign(String secret, String id, long timestamp, String body) {
        return "v1," + Base64.getEncoder().encodeToString(mac(secret, id + "." + timestamp + "." + body));
    }

    /** The merchant's side: the signature must match and the timestamp be recent. Several signatures may be sent, space separated. */
    static boolean verify(String secret, String id, String timestamp, String signatures, String body, Instant now) {
        if (id == null || timestamp == null || signatures == null || body == null) {
            return false;
        }
        long seconds;
        try {
            seconds = Long.parseLong(timestamp);
        } catch (NumberFormatException e) {
            return false;
        }
        if (Duration.between(Instant.ofEpochSecond(seconds), now).abs().compareTo(TOLERANCE) > 0) {
            return false;
        }
        byte[] expected = mac(secret, id + "." + seconds + "." + body);
        for (String signature : signatures.split(" ")) {
            try {
                // Constant time: comparing byte by byte and stopping early tells an attacker how much was right.
                if (signature.startsWith("v1,") && MessageDigest.isEqual(expected, Base64.getDecoder().decode(signature.substring(3)))) {
                    return true;
                }
            } catch (IllegalArgumentException notBase64) {
                // not ours; try the next one
            }
        }
        return false;
    }

    private static byte[] mac(String secret, String content) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(Base64.getDecoder().decode(secret.substring("whsec_".length())), "HmacSHA256"));
            return mac.doFinal(content.getBytes(StandardCharsets.UTF_8));
        } catch (GeneralSecurityException e) {
            throw new IllegalStateException(e);
        }
    }
}

        // The same answer for an unknown username and a wrong password: nothing tells an attacker which accounts exist.
        res.setHeader("WWW-Authenticate", "Basic realm=\"paysetu\"");
        write(req, res, HttpStatus.UNAUTHORIZED, "Sign-in required", "Send a valid username and password.");
    }

    void forbidden(HttpServletRequest req, HttpServletResponse res, AccessDeniedException e) throws IOException {
        write(req, res, HttpStatus.FORBIDDEN, "Not allowed", "This sign-in cannot do this.");
    }

    private static void write(HttpServletRequest req, HttpServletResponse res, HttpStatus status, String title, String detail) throws IOException {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("title", title);
        body.put("status", status.value());
        body.put("detail", detail);
        body.put("instance", req.getRequestURI());
        res.setStatus(status.value());
        res.setContentType("application/problem+json");
        JSON.writeValue(res.getOutputStream(), body);
    }
}

package com.paysetu.webhooks;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.support.TransactionTemplate;

import java.time.Duration;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;

import static org.assertj.core.api.Assertions.assertThat;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

class DuplicateDeliveryMessagingTest extends ApiTest {

    @Autowired
    PlatformTransactionManager transactions;

    @Test
    void twoServersDispatchingAtOnceSendEachDeliveryOnce() throws Exception {
        try (TestMerchant merchant = new TestMerchant(CLOCK)) {
            merchant.delayMillis = 50;   // long enough for the two rounds to overlap
            secretFor("ravi", 1, merchant.url());
            for (int i = 1; i <= 20; i++) {
                testEvent("ravi", 1, "PAY-" + (1000 + i), 100L * i).andExpect(status().isAccepted());
            }
            CountDownLatch start = new CountDownLatch(1);
            try (var servers = Executors.newVirtualThreadPerTaskExecutor()) {
                for (int s = 0; s < 2; s++) {
                    servers.submit(() -> {
                        start.await();
                        return dispatcher.dispatchDue();
                    });
                }
                start.countDown();
            }
            assertThat(merchant.received()).hasSize(20);
            assertThat(merchant.received()).extracting(TestMerchant.Received::id).doesNotHaveDuplicates();
            assertThat(jdbc.sql("SELECT count(*) FROM delivery_attempts").query(Long.class).single()).isEqualTo(20);
        }
    }

    @Test
    void aDeliveryAnotherRoundIsClaimingIsSkippedNotWaitedFor() throws Exception {
        try (TestMerchant merchant = new TestMerchant(CLOCK)) {
            secretFor("ravi", 1, merchant.url());
            testEvent("ravi", 1, "PAY-1001", 100).andExpect(status().isAccepted());
            testEvent("ravi", 1, "PAY-1002", 200).andExpect(status().isAccepted());
            try (var otherServer = Executors.newVirtualThreadPerTaskExecutor()) {
                new TransactionTemplate(transactions).executeWithoutResult(tx -> {
                    jdbc.sql("SELECT id FROM deliveries WHERE id = 1 FOR UPDATE").query(Long.class).single();   // another round, mid-claim
                    Future<Integer> round = otherServer.submit(dispatcher::dispatchDue);
                    assertThat(round).succeedsWithin(Duration.ofSeconds(5)).isEqualTo(1);   // took delivery 2 at once
                });
            }
            assertThat(merchant.received()).hasSize(1);
        }
    }

package com.paysetu.webhooks;

import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpServer;

import java.io.IOException;
import java.net.InetAddress;
import java.net.InetSocketAddress;
import java.nio.charset.StandardCharsets;
import java.time.Clock;
import java.time.Instant;
import java.util.List;
import java.util.concurrent.CopyOnWriteArrayList;
import java.util.concurrent.Executors;
import java.util.function.IntSupplier;

/** A merchant's server for the tests: records what arrives, answers what the test tells it to. */
final class TestMerchant implements AutoCloseable {

    record Received(String id, String timestamp, String signature, String contentType, String body, Instant at) {
        /** What the merchant runs, at the moment the request arrived. */
        boolean verifiedWith(String secret) {
            return WebhookSignature.verify(secret, id, timestamp, signature, body, at);
        }
    }

    private final HttpServer server;
    private final Clock clock;
    private final List<Received> received = new CopyOnWriteArrayList<>();
    volatile IntSupplier answer = () -> 200;
    volatile long delayMillis;

    TestMerchant(Clock clock) throws IOException {
        this.clock = clock;
        server = HttpServer.create(new InetSocketAddress(InetAddress.getLoopbackAddress(), 0), 0);
        server.createContext("/hooks/paysetu", this::handle);
        server.createContext("/elsewhere", x -> {
            received.add(new Received(null, null, null, null, "at /elsewhere", clock.instant()));
            reply(x, 200);
        });
        server.setExecutor(Executors.newVirtualThreadPerTaskExecutor());
        server.start();
    }

    String url() {
        return "http://127.0.0.1:" + server.getAddress().getPort() + "/hooks/paysetu";
    }

    List<Received> received() {
        return List.copyOf(received);
    }

    private void handle(HttpExchange x) throws IOException {
        var h = x.getRequestHeaders();
        received.add(new Received(h.getFirst("webhook-id"), h.getFirst("webhook-timestamp"), h.getFirst("webhook-signature"),
                h.getFirst("Content-Type"), new String(x.getRequestBody().readAllBytes(), StandardCharsets.UTF_8), clock.instant()));
        if (delayMillis > 0) {
            try {
                Thread.sleep(delayMillis);   // a slow merchant, to hit the timeout
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
        int status = answer.getAsInt();
        if (status / 100 == 3) {
            x.getResponseHeaders().add("Location", "/elsewhere");
        }
        reply(x, status);
    }

    private static void reply(HttpExchange x, int status) throws IOException {
        x.sendResponseHeaders(status, -1);
        x.close();
    }

    @Override
    public void close() {
        server.stop(0);
    }
}

     * shortcut: no check of where the URL points (a private address, the cloud metadata service). Before letting
     * merchants register URLs in production, add the address checks of an SSRF-safe fetcher.
     */
    static String checkedUrl(String url) {
        URI uri;
        try {
            uri = new URI(url);
        } catch (URISyntaxException e) {
            throw problem(HttpStatus.BAD_REQUEST, "The URL is not a valid URL.");
        }
        String scheme = uri.getScheme() == null ? "" : uri.getScheme().toLowerCase(Locale.ROOT);
        if (!scheme.equals("https") && !scheme.equals("http") || uri.getHost() == null || uri.getRawUserInfo() != null || uri.getRawFragment() != null) {
            throw problem(HttpStatus.BAD_REQUEST, "The URL must be http or https, with a host and without a user name or #fragment.");
        }
        return uri.toString();
    }

    /**
     * Records that a payment was captured, and one delivery per endpoint, in one transaction (the outbox): either
     * both exist or neither. Reporting the same payment again changes nothing and returns the first event.
     */
    @Transactional
    Recorded paymentCaptured(long merchantId, String paymentRef, long amountPaise) {
        String ref = paymentRef.strip().toUpperCase(Locale.ROOT);
        OffsetDateTime now = now();
        Map<String, Object> data = new LinkedHashMap<>();
        data.put("paymentRef", ref);
        data.put("amountPaise", amountPaise);
        Map<String, Object> payload = new LinkedHashMap<>();
        payload.put("type", "payment.captured");
        payload.put("timestamp", now.toInstant().toString());
        payload.put("data", data);
        Optional<UUID> inserted = jdbc.sql("""
                        INSERT INTO events (id, merchant_id, type, object_ref, amount_paise, payload, created_at)
                        VALUES (?, ?, 'payment.captured', ?, ?, ?, ?)
                        ON CONFLICT ON CONSTRAINT events_once_per_object DO NOTHING RETURNING id""")
                .params(UUID.randomUUID(), merchantId, ref, amountPaise, JSON.writeValueAsString(payload), now).query(UUID.class).optional();
        if (inserted.isPresent()) {
            int deliveries = jdbc.sql("INSERT INTO deliveries (event_id, endpoint_id, next_attempt_at) SELECT ?, id, ? FROM webhook_endpoints WHERE merchant_id = ? ORDER BY id")
                    .params(inserted.get(), now, merchantId).update();
            return new Recorded(inserted.get(), ref, deliveries, false);
        }
        record Existing(UUID id, long amountPaise, int deliveries) {
        }
        Existing first = jdbc.sql("""
                        SELECT e.id, e.amount_paise, (SELECT count(*) FROM deliveries d WHERE d.event_id = e.id) AS deliveries
                        FROM events e WHERE merchant_id = ? AND type = 'payment.captured' AND object_ref = ?""")
                .params(merchantId, ref).query(Existing.class).single();
        if (first.amountPaise() != amountPaise) {
            throw problem(HttpStatus.CONFLICT, ref + " was already reported with a different amount.");
        }
        return new Recorded(first.id(), ref, first.deliveries(), true);
    }

    private static final String DELIVERY = """
            SELECT d.id, d.event_id, e.type, e.object_ref AS payment_ref, w.url AS endpoint_url, d.status, d.attempts,
                   d.last_status_code, d.last_error, d.next_attempt_at, d.delivered_at
            FROM deliveries d JOIN events e ON e.id = d.event_id JOIN webhook_endpoints w ON w.id = d.endpoint_id
            WHERE w.merchant_id = :merchant""";

    /** shortcut: the newest 100, no paging; add a cursor (?after=id) when merchants have more. */
    List<Delivery> deliveries(long merchantId, Status status) {
        return jdbc.sql(DELIVERY + " AND (CAST(:status AS text) IS NULL OR d.status = :status) ORDER BY d.id DESC LIMIT 100")
                .param("merchant", merchantId).param("status", status == null ? null : status.name()).query(Delivery.class).list();
    }

    Optional<DeliveryLog> delivery(long merchantId, long id) {
        return jdbc.sql(DELIVERY + " AND d.id = :id").param("merchant", merchantId).param("id", id).query(Delivery.class).optional()
                .map(d -> new DeliveryLog(d, jdbc.sql("SELECT attempted_at, status_code, error, duration_ms FROM delivery_attempts WHERE delivery_id = ? ORDER BY id")
                        .param(id).query(Attempt.class).list()));
    }

    /** Challenge 1: a dead letter back to pending, due now, from the first attempt. Its old attempts stay in the log. */
    Delivery retry(long merchantId, long id) {
        int updated = jdbc.sql("""
                        UPDATE deliveries d SET status = 'PENDING', attempts = 0, next_attempt_at = ?
                        FROM webhook_endpoints w
                        WHERE w.id = d.endpoint_id AND w.merchant_id = ? AND d.id = ? AND d.status = 'FAILED'""")
                .params(now(), merchantId, id).update();
        Delivery delivery = delivery(merchantId, id).orElseThrow(() -> problem(HttpStatus.NOT_FOUND, "No such delivery.")).delivery();
        if (updated == 0) {
            throw problem(HttpStatus.CONFLICT, "Only a failed delivery can be retried; this one is " + delivery.status() + ".");
        }
        return delivery;
    }

    /** Challenge 2: a new secret. The old one keeps signing for 24 hours, so the merchant can switch over. */
    Endpoint rotateSecret(long merchantId, long endpointId) {
        return jdbc.sql("""
                        UPDATE webhook_endpoints SET previous_secret = secret, previous_secret_until = ?, secret = ?
                        WHERE id = ? AND merchant_id = ? RETURNING id, url, secret, created_at""")
                .params(now().plusHours(24), WebhookSignature.newSecret(), endpointId, merchantId).query(Endpoint.class).optional()
                .orElseThrow(() -> problem(HttpStatus.NOT_FOUND, "No such endpoint."));
    }

    static ErrorResponseException problem(HttpStatus status, String detail) {
        return new ErrorResponseException(status, ProblemDetail.forStatusAndDetail(status, detail), null);
    }

    private OffsetDateTime now() {
        return OffsetDateTime.now(clock).withOffsetSameInstant(ZoneOffset.UTC).truncatedTo(ChronoUnit.MICROS);
    }
}

package com.paysetu.webhooks;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Component;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.support.TransactionTemplate;

import java.io.IOException;
import java.net.ConnectException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.net.http.HttpTimeoutException;
import java.time.Clock;
import java.time.Duration;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.time.temporal.ChronoUnit;
import java.util.List;
import java.util.UUID;
import java.util.concurrent.Executors;

/**
 * Works through the outbox: claims the deliveries that are due, sends each one signed, and records every attempt.
 * Several servers may run it at once: a claimed delivery is invisible to the others until its lease ends.
 */
@Component
class Dispatcher {

    static final int MAX_ATTEMPTS = 8;   // also the deliveries_attempts_range constraint
    static final int BATCH = 20;
    private static final Logger log = LoggerFactory.getLogger(Dispatcher.class);

    private final JdbcClient jdbc;
    private final Clock clock;
    private final TransactionTemplate tx;
    private final Duration firstRetry;
    private final Duration timeout;
    private final HttpClient http;

    Dispatcher(JdbcClient jdbc, Clock clock, PlatformTransactionManager transactions,
               @Value("${paysetu.webhooks.first-retry}") Duration firstRetry, @Value("${paysetu.webhooks.timeout}") Duration timeout) {
        this.jdbc = jdbc;
        this.clock = clock;
        this.tx = new TransactionTemplate(transactions);
        this.firstRetry = firstRetry;
        this.timeout = timeout;
        // Redirects are not followed: the merchant registered this URL, not wherever it points us next.
        this.http = HttpClient.newBuilder().connectTimeout(timeout).followRedirects(HttpClient.Redirect.NEVER).build();
    }

    record Due(long id, int attempts, UUID eventId, String payload, String url, String secret, String previousSecret) {
    }

    /** One round. Returns how many deliveries it tried. */
    int dispatchDue() {
        List<Due> due = claim(now());
        try (var threads = Executors.newVirtualThreadPerTaskExecutor()) {   // one slow merchant does not hold up the rest
            for (Due d : due) {
                threads.execute(() -> {
                    try {
                        attempt(d);
                    } catch (RuntimeException e) {
                        log.warn("Delivery {} could not be recorded; it is tried again when its lease ends", d.id(), e);
                    }
                });
            }
        }
        return due.size();
    }

    /**
     * One statement: the due rows are locked (rows another server has locked are skipped) and their next attempt
     * moved past the lease, so no other round picks them up while we send.
     */
    private List<Due> claim(OffsetDateTime now) {
        return jdbc.sql("""
                        UPDATE deliveries d SET next_attempt_at = :leaseEnd
                        FROM events e, webhook_endpoints w
                        WHERE d.id IN (SELECT id FROM deliveries
                                       WHERE status = 'PENDING' AND next_attempt_at <= :now
                                       ORDER BY next_attempt_at, id LIMIT :batch
                                       FOR UPDATE SKIP LOCKED)
                          AND e.id = d.event_id AND w.id = d.endpoint_id
                        RETURNING d.id, d.attempts, e.id AS event_id, e.payload, w.url, w.secret,
                                  CASE WHEN w.previous_secret_until > :now THEN w.previous_secret END AS previous_secret""")
                .param("now", now).param("leaseEnd", now.plus(timeout).plusSeconds(30)).param("batch", BATCH)
                .query(Due.class).list();
    }

    private void attempt(Due d) {
        OffsetDateTime at = now();
        String id = d.eventId().toString();
        long timestamp = at.toEpochSecond();
        HttpRequest request = HttpRequest.newBuilder(URI.create(d.url())).timeout(timeout)
                .header("Content-Type", "application/json")
                .header("User-Agent", "Paysetu-Webhooks/1.0")
                .header("webhook-id", id)   // the same on every retry: the merchant drops repeats by it
                .header("webhook-timestamp", Long.toString(timestamp))
                .header("webhook-signature", WebhookSignature.sign(d.secret(), id, timestamp, d.payload())
                        + (d.previousSecret() == null ? "" : " " + WebhookSignature.sign(d.previousSecret(), id, timestamp, d.payload())))
                .POST(HttpRequest.BodyPublishers.ofString(d.payload())).build();
        long started = System.nanoTime();
        Integer code = null;
        String error = null;
        try {
            code = http.send(request, HttpResponse.BodyHandlers.discarding()).statusCode();
            if (code / 100 != 2) {
                error = "HTTP " + code + (code / 100 == 3 ? " (redirects are not followed)" : "");
            }
        } catch (HttpTimeoutException e) {
            error = "timed out after " + timeout.toMillis() + " ms";
        } catch (ConnectException e) {
            error = "could not connect";
        } catch (IOException e) {
            error = e.getClass().getSimpleName();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return;   // nothing recorded: tried again when the lease ends
        }
        record(d, at, code, error, (int) ((System.nanoTime() - started) / 1_000_000));
    }

    private void record(Due d, OffsetDateTime at, Integer code, String error, int durationMs) {
        int attempts = d.attempts() + 1;
        String status = error == null ? "DELIVERED" : attempts >= MAX_ATTEMPTS ? "FAILED" : "PENDING";
        OffsetDateTime next = status.equals("PENDING") ? at.plus(backoff(firstRetry, attempts)) : null;
        tx.executeWithoutResult(s -> {
            jdbc.sql("INSERT INTO delivery_attempts (delivery_id, attempted_at, status_code, error, duration_ms) VALUES (?, ?, ?, ?, ?)")
                    .params(d.id(), at, code, error, durationMs).update();
            int updated = jdbc.sql("""
                            UPDATE deliveries SET status = ?, attempts = ?, next_attempt_at = ?, last_status_code = ?, last_error = ?, delivered_at = ?
                            WHERE id = ? AND attempts = ?""")
                    .params(status, attempts, next, code, error, status.equals("DELIVERED") ? at : null, d.id(), d.attempts()).update();
            if (updated != 1) {   // the lease ran out and another round recorded this attempt: keep theirs
                throw new IllegalStateException("delivery " + d.id() + " was recorded by another round");
            }
        });
    }

    /** After the n-th failure: first-retry, then twice as long each time (30 s, 1 min, 2 min, ... 32 min). */
    static Duration backoff(Duration firstRetry, int failedAttempts) {
        return firstRetry.multipliedBy(1L << (failedAttempts - 1));
    }

    private OffsetDateTime now() {
        return OffsetDateTime.now(clock).withOffsetSameInstant(ZoneOffset.UTC).truncatedTo(ChronoUnit.MICROS);
    }
}

        Optional<UUID> inserted = jdbc.sql("""
                        INSERT INTO events (id, merchant_id, type, object_ref, amount_paise, payload, created_at)
                        VALUES (?, ?, 'payment.captured', ?, ?, ?, ?)
                        ON CONFLICT ON CONSTRAINT events_once_per_object DO NOTHING RETURNING id""")
                .params(UUID.randomUUID(), merchantId, ref, amountPaise, JSON.writeValueAsString(payload), now).query(UUID.class).optional();
        if (inserted.isPresent()) {
            int deliveries = jdbc.sql("INSERT INTO deliveries (event_id, endpoint_id, next_attempt_at) SELECT ?, id, ? FROM webhook_endpoints WHERE merchant_id = ? ORDER BY id")
                    .params(inserted.get(), now, merchantId).update();
            return new Recorded(inserted.get(), ref, deliveries, false);
        }
        record Existing(UUID id, long amountPaise, int deliveries) {
        }
        Existing first = jdbc.sql("""
                        SELECT e.id, e.amount_paise, (SELECT count(*) FROM deliveries d WHERE d.event_id = e.id) AS deliveries
                        FROM events e WHERE merchant_id = ? AND type = 'payment.captured' AND object_ref = ?""")
                .params(merchantId, ref).query(Existing.class).single();
        if (first.amountPaise() != amountPaise) {
            throw problem(HttpStatus.CONFLICT, ref + " was already reported with a different amount.");
        }
        return new Recorded(first.id(), ref, first.deliveries(), true);
    }

    private static final String DELIVERY = """
            SELECT d.id, d.event_id, e.type, e.object_ref AS payment_ref, w.url AS endpoint_url, d.status, d.attempts,
                   d.last_status_code, d.last_error, d.next_attempt_at, d.delivered_at
            FROM deliveries d JOIN events e ON e.id = d.event_id JOIN webhook_endpoints w ON w.id = d.endpoint_id
            WHERE w.merchant_id = :merchant""";

    /** shortcut: the newest 100, no paging; add a cursor (?after=id) when merchants have more. */
    List<Delivery> deliveries(long merchantId, Status status) {
        return jdbc.sql(DELIVERY + " AND (CAST(:status AS text) IS NULL OR d.status = :status) ORDER BY d.id DESC LIMIT 100")
                .param("merchant", merchantId).param("status", status == null ? null : status.name()).query(Delivery.class).list();
    }

    Optional<DeliveryLog> delivery(long merchantId, long id) {
        return jdbc.sql(DELIVERY + " AND d.id = :id").param("merchant", merchantId).param("id", id).query(Delivery.class).optional()
                .map(d -> new DeliveryLog(d, jdbc.sql("SELECT attempted_at, status_code, error, duration_ms FROM delivery_attempts WHERE delivery_id = ? ORDER BY id")
                        .param(id).query(Attempt.class).list()));
    }

    /** Challenge 1: a dead letter back to pending, due now, from the first attempt. Its old attempts stay in the log. */
    Delivery retry(long merchantId, long id) {
        int updated = jdbc.sql("""
                        UPDATE deliveries d SET status = 'PENDING', attempts = 0, next_attempt_at = ?
                        FROM webhook_endpoints w
                        WHERE w.id = d.endpoint_id AND w.merchant_id = ? AND d.id = ? AND d.status = 'FAILED'""")
                .params(now(), merchantId, id).update();
        Delivery delivery = delivery(merchantId, id).orElseThrow(() -> problem(HttpStatus.NOT_FOUND, "No such delivery.")).delivery();
        if (updated == 0) {
            throw problem(HttpStatus.CONFLICT, "Only a failed delivery can be retried; this one is " + delivery.status() + ".");
        }
        return delivery;
    }

    /** Challenge 2: a new secret. The old one keeps signing for 24 hours, so the merchant can switch over. */
    Endpoint rotateSecret(long merchantId, long endpointId) {
        return jdbc.sql("""
                        UPDATE webhook_endpoints SET previous_secret = secret, previous_secret_until = ?, secret = ?
                        WHERE id = ? AND merchant_id = ? RETURNING id, url, secret, created_at""")
                .params(now().plusHours(24), WebhookSignature.newSecret(), endpointId, merchantId).query(Endpoint.class).optional()
                .orElseThrow(() -> problem(HttpStatus.NOT_FOUND, "No such endpoint."));
    }

    static ErrorResponseException problem(HttpStatus status, String detail) {
        return new ErrorResponseException(status, ProblemDetail.forStatusAndDetail(status, detail), null);
    }

    private OffsetDateTime now() {
        return OffsetDateTime.now(clock).withOffsetSameInstant(ZoneOffset.UTC).truncatedTo(ChronoUnit.MICROS);
    }
}

Interview takeaways

How do you make sure a webhook is not lost?

Write it to an outbox table in the same transaction as the change, and send it from a background job that retries until a 2xx or a limit.

Exactly once or at least once?

At least once: a timeout after the merchant processed it means we send again. Send a stable id so the receiver can drop repeats.

How does the merchant know a webhook is from you?

An HMAC-SHA256 signature over the id, a timestamp and the raw body, with a shared secret; compared in constant time.

Why sign the timestamp?

So a captured request cannot be replayed later: the receiver refuses timestamps older than a few minutes.

Why exponential backoff?

A merchant that is down gets fewer and fewer requests, and the retries still cover a long outage: 8 tries over about an hour here.

How do two servers avoid sending the same row?

Claim rows with FOR UPDATE SKIP LOCKED and move them past a lease in the same statement.

package com.paysetu.webhooks;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Component;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.support.TransactionTemplate;

import java.io.IOException;
import java.net.ConnectException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.net.http.HttpTimeoutException;
import java.time.Clock;
import java.time.Duration;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.time.temporal.ChronoUnit;
import java.util.List;
import java.util.UUID;
import java.util.concurrent.Executors;

/** Works through the outbox: reads the deliveries that are due, sends each one signed, and records every attempt. */
@Component
class Dispatcher {

    static final int BATCH = 20;
    private static final Logger log = LoggerFactory.getLogger(Dispatcher.class);

    private final JdbcClient jdbc;
    private final Clock clock;
    private final TransactionTemplate tx;
    private final Duration firstRetry;
    private final Duration timeout;
    private final HttpClient http;

    Dispatcher(JdbcClient jdbc, Clock clock, PlatformTransactionManager transactions,
               @Value("${paysetu.webhooks.first-retry}") Duration firstRetry, @Value("${paysetu.webhooks.timeout}") Duration timeout) {
        this.jdbc = jdbc;
        this.clock = clock;
        this.tx = new TransactionTemplate(transactions);
        this.firstRetry = firstRetry;
        this.timeout = timeout;
        // Redirects are not followed: the merchant registered this URL, not wherever it points us next.
        this.http = HttpClient.newBuilder().connectTimeout(timeout).followRedirects(HttpClient.Redirect.NEVER).build();
    }

    record Due(long id, int attempts, UUID eventId, String payload, String url, String secret) {
    }

    /** One round. Returns how many deliveries it tried. */
    int dispatchDue() {
        List<Due> due = claim(now());
        try (var threads = Executors.newVirtualThreadPerTaskExecutor()) {   // one slow merchant does not hold up the rest
            for (Due d : due) {
                threads.execute(() -> {
                    try {
                        attempt(d);
                    } catch (RuntimeException e) {
                        log.warn("Delivery {} could not be recorded", d.id(), e);
                    }
                });
            }
        }
        return due.size();
    }

    /** Simpler: read what is due. The update after sending moves it on, so it is not sent twice. */
    private List<Due> claim(OffsetDateTime now) {
        return jdbc.sql("""
                        SELECT d.id, d.attempts, e.id AS event_id, e.payload, w.url, w.secret
                        FROM deliveries d JOIN events e ON e.id = d.event_id JOIN webhook_endpoints w ON w.id = d.endpoint_id
                        WHERE d.status = 'PENDING' AND d.next_attempt_at <= :now
                        ORDER BY d.next_attempt_at, d.id LIMIT :batch""")
                .param("now", now).param("batch", BATCH)
                .query(Due.class).list();
    }

    private void attempt(Due d) {
        OffsetDateTime at = now();
        String id = d.eventId().toString();
        long timestamp = at.toEpochSecond();
        HttpRequest request = HttpRequest.newBuilder(URI.create(d.url())).timeout(timeout)
                .header("Content-Type", "application/json")
                .header("User-Agent", "Paysetu-Webhooks/1.0")
                .header("webhook-id", id)   // the same on every retry: the merchant drops repeats by it
                .header("webhook-timestamp", Long.toString(timestamp))
                .header("webhook-signature", WebhookSignature.sign(d.secret(), id, timestamp, d.payload()))
                .POST(HttpRequest.BodyPublishers.ofString(d.payload())).build();
        long started = System.nanoTime();
        Integer code = null;
        String error = null;
        try {
            code = http.send(request, HttpResponse.BodyHandlers.discarding()).statusCode();
            if (code / 100 != 2) {
                error = "HTTP " + code + (code / 100 == 3 ? " (redirects are not followed)" : "");
            }
        } catch (HttpTimeoutException e) {
            error = "timed out after " + timeout.toMillis() + " ms";
        } catch (ConnectException e) {
            error = "could not connect";
        } catch (IOException e) {
            error = e.getClass().getSimpleName();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return;
        }
        record(d, at, code, error, (int) ((System.nanoTime() - started) / 1_000_000));
    }

    private void record(Due d, OffsetDateTime at, Integer code, String error, int durationMs) {
        int attempts = d.attempts() + 1;
        String status = error == null ? "DELIVERED" : "PENDING";   // merchants want every payment: keep trying until it works
        OffsetDateTime next = status.equals("PENDING") ? at.plus(firstRetry) : null;   // every 30 s, so it arrives soon after they are back
        tx.executeWithoutResult(s -> {
            jdbc.sql("INSERT INTO delivery_attempts (delivery_id, attempted_at, status_code, error, duration_ms) VALUES (?, ?, ?, ?, ?)")
                    .params(d.id(), at, code, error, durationMs).update();
            jdbc.sql("""
                            UPDATE deliveries SET status = ?, attempts = ?, next_attempt_at = ?, last_status_code = ?, last_error = ?, delivered_at = ?
                            WHERE id = ?""")
                    .params(status, attempts, next, code, error, status.equals("DELIVERED") ? at : null, d.id()).update();
        });
    }

    private OffsetDateTime now() {
        return OffsetDateTime.now(clock).withOffsetSameInstant(ZoneOffset.UTC).truncatedTo(ChronoUnit.MICROS);
    }
}

Findings

1Two servers send the same delivery

"The update after sending moves it on": but between the SELECT and that update, the HTTP call takes as long as the merchant does. Another server's round, a second later, reads the same rows and sends them again. Every app with two instances sends duplicates. The claim must move the row on before sending, in the same statement that picks it (here: a lease, with SKIP LOCKED).

Test evidence: twoServersDispatchingAtOnceSendEachDeliveryOnce and aDeliveryAnotherRoundIsClaimingIsSkippedNotWaitedFor fail.

2Retrying every 30 seconds, forever

"So it arrives soon after they are back": and a merchant that is down for a day gets 2,880 requests per payment, all at once when it comes back. The waits must grow. And "never give up" hides the problem: nobody is told the delivery failed. Worse, the database's limit of 8 attempts makes the ninth try's record fail: the row is unchanged and still due, so it is sent again on every round, every second.

Test evidence: theWaitDoublesAfterEachFailureAndTheEighthFailureIsFinal and theApiKeepsThePaymentUntilTheMerchantIsBack fail.
